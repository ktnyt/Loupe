# 自動付与で写真をまとめる

2026-10-25。Issue #1、作業ID `20261025-issue1-auto-tags`。

## 合意と目的

少数の手動判断から、残りにもタグが付いて集合として利用できることを実現する。ユーザーは「多少の誤付与を許容し、広く自動で付ける」を選択した。以前の独立評価済み範囲だけを自動化する提案は、今回の明示操作による「未校正の推定を広く付与するモード」に置き換える。精度保証や確率表示はしない。

## 実装前の契約

- 「自動でタグを広げる」で、現在のアルバム・カメラ範囲に対して開始する。一枚以上の手動正例が必要。タグDBに自動結果を保存し、手動と合わせて付与済み閲覧へ出す。自動／手動の件数と由来を表示する。
- 既存の画像特徴を使い、各候補の最大正例類似度と最大負例類似度を計算する。初期閾値はcosine 0.55、正例が複数ある場合は正例同士の最近傍類似度の下位10%から0.15引き、0.40〜0.65へ制限する。負例がある場合は正例類似度が負例類似度を0.02以上上回るものを付ける。これらは広く付与するためのヒューリスティックであり正解率ではない。
- 自動結果を正例・負例へ混入しない。手動判断が常に優先。手動除外と、明示的な判断取消（未判断へ戻した履歴あり）は自動付与対象から外す。取消は負例にはしない。
- 自動結果は写真参照・手動判断版・モデル／判定器版・閾値・類似度・自動化世代を持つ。手動訂正で版が変わった結果は付与済み集合から外し、現行判断で再計算する。
- `tags.db` v1→v2は既存表を保持した追加表のみ。自動結果の更新はトランザクション内で手動版・有効状態・世代を再確認し、古い処理を拒否する。対象の解析済み写真だけを置き換え、他のアルバムの同じ版の結果は保持する。
- 解析中は一定枚数ごと、解析終了時、手動判断・undoの後に再計算する。現在表示中の写真は勝手に入れ替えない。保存失敗では完了表示しない。
- 終了・停止で未確定の処理をキャンセルし、保存済み結果は残す。「自動付与をすべて取り消す」はそのタグの自動結果だけを消し、手動結果は保持する。停止／取消後の古い処理は再保存できない。
- パスは当該セッションの提示を保留する操作で、自動付与の拒否ではない。その意味を画面に表示する。自動付与を拒否する操作は「該当しない」または「判断を取り消す」。
- 解析・判定は端末内。写真の外部送信・原本・EXIF・共有選択・連写順位の変更はない。画面を閉じた後の常駐解析は行わない。

## 検証予定

自動結果の永続化・付与済み統合・手動優先・取消・undo・版変化による失効、停止競合、移行、モデル違い、正例ゼロ、未解析、正負例での適用範囲変化を検証する。精度・再現率の評価は別であり、機能の動作確認と区別する。

## 付与済みの閲覧

「付与済みの写真を見る」と「自動付与した写真だけ見る」はサムネイル一覧を開く。タップで拡大し、前後ボタン・左右スワイプは閲覧位置だけを変える。「この写真のタグを訂正」を押した場合だけ判断画面へ進む。閲覧だけでは判断・自動付与・再判定を実行しない。

## 画面の離脱と復帰

別アプリへの移動時は処理中の画像を終えた境界で一時停止し、同じActivityへ戻ると解析済みの特徴・件数を保持して残りを処理する。進捗表示のたびに全写真の付与数を走査しない。終了操作やActivity破棄を伴う場合は別の開始として扱い、永続化した特徴キャッシュを再利用する。バックグラウンド常駐処理は行わない。
