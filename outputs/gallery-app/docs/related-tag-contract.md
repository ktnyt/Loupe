# 見本からタグを広げる（実装前の契約）

2026-10-25。Issue #1のT2・T3を実装する。ユーザーから、既存の付与例を起点に関連候補を提示し、判断で候補を更新するところまで依頼された。既存の手動タグ・写真同一性・左右操作の契約を継承する。

- 対象は現在のアルバム・カメラ絞り込み内の端末写真。全写真から探す場合は「すべての写真」から開く。正負例も同じ範囲から取得する。範囲外の見本があることを未判断と混同しない。
- MobileNetV3 small float32 version 1 / MediaPipe Tasks Vision 0.10.35を同梱し、端末CPUで画像特徴を抽出する。JPEGとRAW内の向き補正済みプレビューを使う。写真の送信・原本変更・タグ自動付与をしない。意味の一致・人物個体識別・好みの理解を保証しない。
- 特徴キャッシュはタグDBから独立した再生成可能なDB。写真参照の版とパイプライン版をキーにする。モデル不一致、次元不一致、非有限・ゼロベクトルは候補に使わない。中断後は完成済みキャッシュを再利用する。
- 正例の最大類似度を使い、複数の見本を平均に潰さない。負例の最大類似度で順位を下げる。スコアは確率として表示しない。5枚に1枚は正例から遠い候補を提示し、検索上位だけへの偏りを抑える。
- 付与済み・明示的除外済み・このセッションで確認済みの写真は候補から除く。パスは判断を変更しない。undoで直前の写真に戻り、保存した正負例も復元して残りを再計算する。
- 正例がないときは見本を選ぶ手動確認へ誘導する。初回付与後は関連候補へ進む。特徴抽出に失敗した写真を除外判断にしない。解析数・対象数・失敗数を表示する。
- 特徴抽出は画面・保存用とは別の単一ワーカーで実行。現在表示中の写真を非同期更新で勝手に差し替えない。画面終了時に解析をキャンセルし、古いセッションの結果を破棄する。判断保存失敗では次に進まない。
- 初回は見本を優先し、残りは一覧の全域から均等に巡回する。解析途中の候補を利用できる。再評価はその時点の確定判断だけから計算し、自動結果を正例にしない。

## 検証予定

正例追加と負例追加による順位変化、複数見本、パス・undo、未解析、異なる特徴次元、不正特徴、キャンセル、キャッシュ復元、実機モデル推論、既存タグ保全、画面遷移。精度のA/B/C比較・自動付与の閾値決定は別段階。

## 実装と検証

- `PhotoFeatures`: 公式モデル（SHA-256 `bbbb4c51a55a53905af1daec995ca1aae355046f8839bb8c9f5ce9271394bc40`）とパイプライン版、1024次元のint8特徴キャッシュ。ランタイムは0.10.35固定。浮動小数出力を最大絶対値で量子化し、検索はノルムで補正したcosineを使う。
- `RelatedPhotos`: 最大正例類似度−0.5×最大負例類似度を候補順位に使う。重みは実装上の初期値で、精度を保証する値ではない。5回に1回は最大正例類似度の低い写真を探索候補にする。
- `TagActivity`: 候補画面、保存後の再計算、パスとundo、初回見本からの接続、非同期結果の世代確認と中断。最初の32枚から開始し、現在表示中の候補を固定する。
- `TagStore.photoIds`: 参照対応をまとめて読み、写真ごとのDB問い合わせを避ける。タグDBのスキーマは変更しない。
- 判断モデルと候補検索の単体テスト成功。正例追加・undo・負例による順位変化、パスの非負例性、探索枠、未解析・不正特徴を検証。
- 既存の保存・共有準備テスト、クラウドURLポリシー22項目が成功。依存ライブラリ追加後も必要なクラスだけをjavacでコンパイルするようテストスクリプトを修正。
- `assembleDebug assembleDebugAndroidTest lintDebug`成功（0エラー・29警告）。うち追加分は依存の新バージョン案内と文字列連結。
- 実機: モデルの繰返し推論、既存見本を含む19枚の解析（失敗0、正負例11）、未判断候補生成、特徴キャッシュ再接続、判断履歴不変を確認。計測426msはこの小範囲・既存プレビューでのテスト全体。全ライブラリ初回処理・精度・発熱の保証ではない。
- 初回実機テストでMPImage.closeが入力Bitmapを解放し、繰返し推論がクラッシュした。推論専用コピーを渡して所有権を分離し、上記の再実行で成功。
- 実機UIで既存タグの11枚付与・8枚未判断を読み出し、関連候補表示、左スワイプで別候補へ進むこと、一つ戻すで元の候補へ戻ることを確認。表示画面もスクリーンショットで確認。利用者の実タグを付与・除外する操作はしていないため、その画面操作の実測は未実施（順位変化は単体、保存は別の実機テストで検証）。
- まだ未検証: 大量ライブラリでの負荷、タグ別検索精度、同じ連写の偏り低減、A/B/C比較、自動付与の許容誤付与率。候補生成・判断更新の体験を実装した段階で、Issue #1全体の完了ではない。
