# タグ操作の整理（Issue #1）

主画面は「写真を見る」「写真を追加」「自動で探す」。現在のアルバム・カメラ範囲を明示する。自動のみ・外した写真・一括取消は「その他」にまとめる。

閲覧はタップで拡大、左右は移動のみ。写真の状態は「タグあり」「タグなし」。手動／自動は由来の補足。変更は「タグを付ける」「タグを外す」のみとし、その写真に留まる。外す操作はEXCLUDEDとして保存し、再自動付与を防ぐ。既存のUNDECIDED履歴は破棄せず抑制を保持する。パス、候補選別、判断取消、暗黙の自動再開をUIから除去する。

自動処理は明示開始のみ。実行中は進捗と「停止して写真を見る」、完了後は「結果を見る」。他画面へ遷移すると停止する。停止済みの保存結果は残る。

手動訂正で他の自動結果を消さない。保存済みの旧判断版の結果は、本人の直接判断がある写真を除き、次回の明示的な自動処理まで維持する。最新の訂正を他の写真へ反映するには「自動で探す」を実行する。この規約はautomatic-tag-contractの旧判断版を非表示にする規約を置き換える。古い実行結果の新規書込みを拒否するrevision/epoch検査は維持する。
