# 旧取り込み写真の移動前確認

撮影日時の秒が履歴と1秒ずれる写真や、撮影日時を取得できない写真も、端末の原本と検証済みバックアップが同じと確認できれば移動できる。現行の取り込み履歴およびカメラのチェックサムで確認できる写真には既存の条件を適用する。

## 照合条件

- 候補は、内部ストレージの取り込みフォルダにある公開済みの写真で、Loupeが所有し、読み書きと原本の参照が可能なものに限る。実ボリューム、集約URIの一意性、取り込み履歴の1件への紐付き、カメラの記録との矛盾がないことを確認する。
- 履歴の撮影時刻は正の偶数秒とする。写真の時刻はその1秒後か、不明を示すNULL、0、-1に限る。元のファイル名または取り込み時に付けた名前に一致し、同じサイズである必要がある。ファイルの更新時刻は取り込み時刻と一致し、追加時刻は取り込み時刻の1秒前から取り込み時刻までとする。
- 検証済みのE2記録のフォルダ、名前、サイズ、更新時刻、追加時刻が端末の写真と一致し、確認日時が取り込み時刻以降である必要がある。現在のアプリからMediaStoreのバージョンを取得し、写真が追加されてから現在までの世代番号について、E2記録のキーを再構成する。世代差は256以下とし、範囲を最後まで確認して一致が1件の場合に限る。照合処理の上限に達した場合や中断した場合は、確認できなかった写真を元の場所に残す。

## 確認と移動

保存場所の一覧はメタデータの照合まで行う。移動の操作では、候補ごとに原本を最後まで読み、バイト数とSHA-256を検証済みE2記録と比較する。読み取りの前後で写真、MediaStoreのバージョンと世代、所有者、アクセス権を確認する。検証済みのE2記録は照合の前後と移動中に確認し、同じ写真を指す別のE2記録が存在する場合は、その記録の状態にかかわらず移動の根拠に使わない。この確認では移動先にファイルを作成せず、履歴やE2の記録を更新しない。確認できた枚数と容量、対象外の項目を表示し、利用者が確認画面で「移動」を選んだ場合に限り、その確認結果で移動を始める。確認は中止できる。

移動中の記録には、確認した旧取り込み履歴とE2記録の根拠を保持する。途中で終了して再開しても、この履歴を別の取り込み記録で代用できない。コピーしたバイトがE2記録と一致することを確認し、公開前と公開後の照合、参照先の更新、元の写真の再照合を経てから削除する。参照先の更新前と削除前に、フォルダと写真の撮影日時が移動元と一致することを確認する。撮影日時のNULL、0、-1は同じ未取得状態として扱う。E2記録を移動先の参照に書き換えたり、クラウドの整理権限として扱ったりしない。

## 移動後の記録と再移動

旧履歴の撮影日時と、コピー先の写真の撮影日時は変更しない。移動時に照合したSHA-256と旧履歴の識別子を、移動先で実際に公開された写真のURI、MediaStoreのバージョン、追加・更新世代、メタデータに紐付けて保存する。次に移動するときも、この記録と旧履歴の現在の参照先が一致し、写真の原本を最後まで読んで同じSHA-256を確認できることが条件となる。

移動元の削除前に、それまでの記録と新しい移動先の照合結果を作業中の記録に残す。削除後に、この作業を終えた記録と新しい参照先の根拠を同じトランザクションで確定する。削除前に終了する場合は、元の写真を確認して参照先を戻し、以前の根拠を保持する。選んだ履歴が消去されている場合は、写真を残したまま終了し、履歴を作り直さない。削除後に中断した場合は、作業中の記録と移動先の原本を再確認して確定する。履歴が消去済みでも、移動先の写真とタグなどの関連付けは保持し、再移動用の根拠は作らない。

移動先の作成前に、対象ボリュームのMediaStoreバージョンと一時ファイル名を作業記録へ保存する。再開時は同じボリュームとバージョンで一時ファイルを一意に確認できた場合だけ、作成した写真のURIと追加世代を確定する。コピーの前後でこの組み合わせを確認し、保存先の写真が見つからなくなった場合に作り直して代用しない。移動先を元の内容が残るモードで開き、写真を再確認して読み取り用と書き込み用が同じファイルを指すことを確かめる。確認後は開いた書き込み先だけに書き込む。公開前の照合では更新世代も記録する。公開後は同じ写真の全バイトとフォルダ、撮影日時、形式、公開名を確認し、公開状態の更新世代とメタデータを参照先の変更前に記録する。旧記録で移動先の識別情報が不足している場合は、既存のコピーを代用したり削除したりしない。

移動先の関連付けを作成したときに、その行を作業記録に残す。移動元を確認して参照先を戻すときは、この移動で作成した行と現在の行が一致する場合だけ、その関連付けを取り除く。作成した行を記録していない場合や既に別の行になっている場合は、関連付けを保持する。
