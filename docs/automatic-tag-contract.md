# タグの推定結果の保存と互換性

現行の判定・スコア・閾値は[タグConfidence](tag-confidence-contract.md)に従う。人の判断と推定結果を別々に保存し、手動付与・明示的除外・取消抑制が常に優先される。推定を学習標本にしない。

`tags.db` v3は、v1/v2の写真参照・判断・履歴・再評価要求・旧自動結果を保全して、タグ別の閾値・学習有効状態・処理世代、モデル、全スコアの表を追加する。写真参照はURIと観測した版の対応であり、移動や別コピーの同一性を保証しない。

旧`automatic_tags`の結果は旧パイプラインと判定器版が一致する場合だけ読み、当該タグの最初の完成したConfidenceモデルまで使う。旧類似度をConfidenceへ変換しない。新しいモデルができたタグでは旧集合を重ねず、保存済みスコアとタグ別閾値から表示集合を求める。モデルの形式は寸法・長さ・有限値を検査する。

モデルと全スコアを同一トランザクションで置き換え、手動判断版・有効状態・処理世代を再確認する。世代は再計算の開始ごとにも進め、並行する旧キャッシュ集合の書戻しを拒否する。失敗・中止・見本不足では直前の完成結果を保持する。手動訂正で旧版となった結果は、本人の直接判断を優先して前回結果として表示する。

自動結果の全解除は当該タグの旧集合・モデル・スコアを削除し、再学習を無効にして世代を進める。本人の判断と閾値は残す。写真を解析で明示的に再開する。停止は処理世代を進めて未確定ジョブだけを拒否し、完成結果と後続の明示判断による再学習は保つ。

解析・学習は端末内。別アプリへ移動すると処理中の画像を終えた境界で一時停止し、同じActivityへの復帰で続ける。Activity終了時は未確定処理を止める。写真送信・原本・EXIF・共有選択・連写順位の変更、常駐処理を行わない。

検証は単体の学習/判断テスト、隔離DBの`confidence-store`、生成写真と隔離DBの実画面`tag-confidence`、従来の`tag-detail`で行う。実測の環境・範囲と未確認事項はissue #46へ記録する。
