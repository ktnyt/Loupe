# USBカメラ取り込み

カメラを接続し、写真・RAW・動画の新規分をLoupeに取り込める。旧CameraSyncの機種設定と取り込み履歴は、同じ端末で引き継げる。

- [参照HTML](design/loupe-camera-import.html) の写真一覧 S02 と設定 W03 を基準にする。設定から接続の有無、進捗と最後の結果を確認できる。端末のUSB許可とハンドラ選択はAndroidに委ねる。
- MTPとUSBマスストレージの両方で機種ごとの履歴を使う。保存先はCameraSyncと同じMediaStoreのパス。公開済みメディアのみ履歴へ登録する。中断時は公開済み分を残す。
- 移行にはCameraSyncが書き込み中でない時点のSQLiteスナップショットを使う。機種とシリアル、ファイル名・サイズ・撮影日時で照合し、既存のLoupeの設定と履歴を優先する。エラー時は移行全体を取り消す。元のDB・アプリ・メディアは変更しない。
- 移行した機種のカメラ側削除はオフ。USB接続から始まる自動取り込みでは原本を削除しない。手動取り込みでカメラ側削除を指定した場合も、対応するMTP機種で保存と履歴登録に成功した原本だけを対象にする。

［その他］の設定から［カメラから取り込む］を開く。初回に対象形式を選び、次回からの自動取り込みを設定できる。カメラごとの端末保存先は最初の取り込み後に変更できる。自動取り込みを使う場合、旧CameraSyncがAndroidの既定ハンドラなら、旧アプリの設定で既定を解除し、次回の接続時にLoupeを選ぶ。旧アプリのストレージは消去しない。

［記録のファイルを選ぶ］で、旧アプリの書き込みが完了した時点の `history.db` のスナップショットを選ぶ。以前の名前・サイズ照合だけで記録された可能性がある `existing` 行は移行時に取り込み済みとは扱わず、次回に保存先との照合を行う。撮影済み動画もMediaStoreへ保存する。Loupeの写真一覧での動画再生はこの機能の対象に含まない。

MTPで端末へ転送した長さがカメラの報告サイズと一致しない場合、保存済みとして扱わない。4GiB以上の動画で報告サイズが折り返す機種はUSBマスストレージ経路を使う。全形式のMTP列挙に失敗した場合は「新規なし」と表示せず、接続を再試行する。

OM Digital Solutions／OlympusとPanasonicはAndroidのUSB接続ハンドラから自動取り込みできる。その他のBOT対応USBストレージ（カードリーダーなど）は、カメラ取り込み画面から手動で選ぶ。対象の保存媒体はexFATのDCIM。

対応するUSB機器が接続されている間、「すべての写真」「アルバム」の横に「カメラ」を表示する。タップで設定を開き、長押しで取り込む。長押しではカメラ側を削除しない。許可や初回設定が必要なら先に行う。写真選択中はタブ操作を無効にし、取り込み中の長押しは開始を重ねない。切断でタブを隠し、現在のライブラリ画面を保つ。
