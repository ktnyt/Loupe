# 連写の同率1位指定

対象: Issue #82。目的は、連写の残したい写真を1枚ずつ同率1位へ追加できること。

## 要件・契約

- 確定済み連写の非1位写真は、確認画面から同率1位へ追加できる。既存1位を保持し、残る写真の相対順と同順位グループを保持して競技順位を再計算する。既に1位なら追加は不要で表示しない。
- 未着手・途中は既存の単独1位指定で確定できる。単独指定は選択写真を1位、残りを同率2位にする。個別解除は追加せず、単独指定と再ソートを保持する。
- 確認の取消・Back・外側タップでは保存しない。保存中は操作を重複させない。成功時だけ画面とキャッシュを更新し、同じ連写・写真へ戻る。失敗時は前の順位を保持し、同じ操作を再試行できる。
- 順位印、読み上げ、1位フィルター、共有対象は同じ確定結果を参照する。写真原本・タグ・共有の一時選択は変更しない。
- 保存キーと旧履歴の読込を維持する。同率追加後の結果は既存の全順位履歴として保存する。比較の取消は従来どおり比較履歴を一手ずつ戻す。

## UI

[参照HTML](design/loupe-burst-co-winners.html)の同率追加確認・成功・失敗・順位印を適用する。既存の連写詳細の配置と操作を維持し、プレビュー読込中・失敗でも順位操作を妨げない。320dpおよび通常幅、文字1/1.3倍で操作領域48dp以上と折返しを確認する。

## 検証

モデルで順位・互換性、保存境界で成功/失敗、合成実機操作で確認/取消/再試行/位置保持と共有対象を検査する。写真原本や秘密情報は試験に使用しない。性能は保存開始から画面更新のフレームまでを計測し、保存処理時間だけと区別する。結果・未検査範囲はissueの工程記録を参照する。
