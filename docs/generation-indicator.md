# AI生成とカメラ待機の表示

目的・要件・実装前の契約は [#118](https://github.com/ktnyt/Loupe/issues/118) を参照する。

AI編集の実行中は、前面のActivityまたはダイアログに共通の小さな状態表示を置く。視覚表示は28dp、操作領域は48dp。既存のボタン・入力欄・スライダーを避け、system barsとdisplay cutoutを含むウィンドウ境界内に配置する。写真や画面レイアウトを縮めず、タップ、または前面ウィンドウでCtrl+Shift+Gを押して既存の処理状況メニューを開く。保存直後の同じショートカットは生成画像を開く。

- 実行中はMaterialの円形進捗表示。動きを無効にしている場合は静止した記号で示す。
- 後処理だけの完了は保存画像の案内と区別する。
- 保存完了はチェックと「開く」付きのSnackbarで示す。前面では同じ結果のToastを重複させない。背景で完了した場合は次の前面表示で案内する。
- 中断・失敗・未処理のjobは確認を促す表示に変える。表示やメニューを開くだけでは生成要求を送信しない。
- 「開く」は公開済みでLoupeが所有するMediaStore画像だけを既存の写真ビューアーへ渡す。

表示はアプリ自身のウィンドウに限り、他アプリの上には出さない。背景では表示とアニメーションを止め、Activityの参照を解放する。APIキー設定などのFLAG_SECUREは維持する。生成の受付・送信・保存・一時画像の後処理は既存のServiceとJobが担う。

カメラ接続・応答待ち・再試行待ちはImportProgressの明示的なwaiting状態で伝える。取り込みタブのバッジは待機中だけゆっくり明滅し、スキャン開始後は件数表示に戻る。枚数ゼロを接続待ちとは判定しない。非表示やdetach、システムの動き無効設定では明滅を止め、読み上げ用の状態説明を維持する。
