# Nano Bananaで写真を編集する

「その他」→「設定とその他」→「Nano Banana」で、NanoBananaAPI.aiのAPIキー、IDrive e2東京のバージョニング有効な既存バケットとアクセスキー、名前付きプロンプトを登録する。登録済みのキーは画面へ再表示しない。キーはAndroid Keystoreで暗号化して端末内へ保存する。設定画面は画面キャプチャを禁止する。

「出力」でアスペクト比と出力解像度（1K・2K・4K）を選んで保存する。初期値は自動・1K。料金は選ぶ解像度によって変わる。出力設定は新しく始める編集に適用し、進行中の依頼や「状態を再確認」では依頼時の値を使う。既存の処理記録に設定がない場合は従来の自動・1Kとして扱う。

出力サイズの指定は送信画像の画素数とは別であり、送信画像は長辺1600px以下のまま。元写真と同じ画素数・細部の保持を保証する設定ではない。

写真を開き「AI編集」からプロンプト名を選ぶと、画面を移動せずバックグラウンドでNanoBananaAPI.aiのNano Banana 2へ1回依頼する。送信用の長辺1600px以下のJPEGには原本のEXIFを引き継がない。e2の`loupe-nano-temp/<UUID>.jpg`に保存し、成功した版に固定した30分有効な読み取りURLを渡す。API利用料金とe2転送・保存料金は利用アカウントに従う。原本へは書き込まない。

結果は20,000,000px以下・20MiB以下の画像を検査し、画素数を縮小せず別JPEGとして`Pictures/LoupeNanoBanana`へ保存する。保存が完了すると短いトーストで知らせる。生成中も写真の閲覧や他の操作を続けられる。実行中はAndroidの通知を表示し、同時に開始できる処理は1件とする。APIの生成タスクIDと保存の状態は端末へ記録する。通信断後の「状態を再確認」は同じタスクを取得し直し、新しい生成依頼は送らない。生成依頼の結果が不明な場合は自動再送せず、その旨を表示する。

生成後に、送信前に記録した所有識別子を確認してe2の一時画像を版指定で削除する。削除に失敗したら次の生成を止め、「AI編集」の「後処理を再試行」から再試行できる。「処理を終了」では保存済みの生成結果を残す。サービス側の生成や課金を取り消せるとは限らない。期限付きURLの失効はe2上の画像削除とは異なる。

e2の認証情報に誤りがあった場合は、処理が動いていないときに同じバケットのキーを修正できる。処理が残っている間は送信先バケットを変更できない。設定を削除する前に一時画像の削除を終える。

アプリを離れてもサービスが処理を続ける。Androidによる終了や通信断で処理が残った場合は、写真の「AI編集」または設定の「生成の状態」から再確認や後処理を行う。動画はこの編集の対象に含めない。

結果画像はサービスの公開Playgroundが使う`tempfile.aiquickdraw.com`と`file.aiquickdraw.com`からのみ取得し、リダイレクトは追わない。サービスの配信先が変わった場合は取得に失敗し、タスクを保持する。

提供先はNanoBananaAPI.ai。Google公式Gemini APIのキーとは互換ではない。Google公式への通信先変更は行わない。

API仕様は[Nano Banana 2](https://docs.nanobananaapi.ai/nanobanana-api/generate-image-2)と[タスク取得](https://docs.nanobananaapi.ai/nanobanana-api/get-task-details)を参照する。
