# グローバルなポイントカーブ

## 目的と合意
白に近い被写体の階調、暗部の質感、中間調の硬さを画像全体の変換として調整する。局所マスキングは導入しない。Issue #63。旧実験パラメータは利用者の指定により破棄する。旧レンダラー・互換モード・移行処理を設けない。写真原本と既存JPEGは変更しない。

## 数値契約
- カーブは明度、RGB合成、R、G、Bの5本を独立保持し、この順で合成する。編集対象の選択は他のカーブを無効にしない。
- 各曲線は2〜32点。入力・出力は0〜1、入力の最小間隔1/128、出力非減少。端点も入力・出力を移動できるが削除できない。選択端点には外側のリングを表示する。定義域外は端点出力へ固定する。
- 区分三次HermiteのPCHIP（内部傾きは区間長で重み付けした調和平均、端点は片側式と符号/3倍制限）。平坦区間の傾きは0。
- LUTは8193サンプル/曲線、float32。GPUはnearest格納＋明示的線形補間。1024px幅へ折り返し、端点を含む。CPUの解析評価に対し絶対誤差0.0003以下を数値検証する。
- ロールオフrは0〜1、既定0.5。Oklab Lに対しk=1−0.3r、L<=kは不変、L>kはk+(1−k)(1−exp(−(L−k)/(1−k)))。r=0では上限1の無圧縮クリップ。r>0は接続点で値と一次導関数が連続、0〜32で非減少。上流で失ったRAW情報の復元は保証しない。
- 基本階調もPCHIPで構成。黒/白は入出力端点、シャドウ/ハイライトは内側アンカー、コントラストは中間調の勾配、明度は内側全体を動かす。アンカーを非減少へ制約し、合成グレー変換の反転を防ぐ。
- 処理順: 線形RGBのWB・露出 → 既存の質感/明瞭度/かすみ → Oklab変換 → ロールオフ → 基本階調 → 明度カーブ → RGB合成カーブ → R/G/B → Oklabで彩度/バイブランス → 色域調整 → sRGB符号化 → 最終8bit量子化。
- RGB曲線の座標はsRGB符号値（必要な往復変換を行う）。明度曲線の座標はOklab L。明度とRGB合成を同じ変換と扱わない。
- Oklabは符号付き立方根を使い、ゼロ輝度で除算しない。色域外の色はLとa:bの方向を保ち、a/bの共通係数を16回二分探索する。RGB往復の丸め誤差で境界色を過剰に圧縮しないよう、初回の色域判定は2e-6の数値許容を設け、その範囲だけ0〜1へ丸める。二分探索の判定は厳密範囲を使う。黒/白/無彩色は有限な中性色へ収束する。全域で彩度を保つ保証はしない。
- ソースGPU格納はRGBA32Fへ変更し、float32の明示的双線形補間で16bitキャッシュの精度を保持する。演算途中のRGBの負値・1超の値は色域変換前にチャンネル別クリップしない。8bit化は最終段のみ。最終量子化には固定4×4 Bayerディザ（0.5 code未満）を画素座標に基づいて適用し、表示/タイル/保存で一致させる。

## 状態・操作契約
- 新しいスナップショットは版識別子・スカラー値・全5曲線を含む。旧16/17値配列は拒否し、Activityの旧Bundleは全パラメータを既定へ戻す。NaN/無限大/範囲違反/余分な末尾は拒否する。
- コピーは不変。Undo/Redoは1回のドラッグ/スライダー操作を1単位とし、点追加/削除/リセットも取り消せる。履歴上限64。新規編集でRedoを破棄する。ピンチ/CANCELで操作前へ復元し履歴を追加しない。
- Bundle再生成と保存ジョブのスナップショットに全曲線を含む。比較/MAXは一時表示で保存データに含めない。写真の保存は既存の別JPEG、原本不変/失敗時cleanupの契約を保つ。
- UIはClaude完成HTMLを参照する。既存の7タブ/比較/保存/原寸準備/写真移動を維持。トーンタブだけグラフ・5編集対象・選択値・点削除・Undo/Redo・ロールオフを持つ。

## 数値設計の結果と検証計画
`scripts/tone-curve-numerics.py`の設計試験では64曲線/1048640評価、LUT最大誤差0.000120175（8bit換算0.031）、0〜32のロールオフ単調性、10000色の色域内への写像を確認した。倍精度の設計試験であり、GPUの保証とは区別する。

実装のホスト検査はPCHIP端点/単調性/有限値/不正入力/状態往復/履歴/6種類の合成画像。端末GPUでCPU参照との誤差、タイル一致、保存JPEG、画面再生成、実操作・読み上げ用操作・画面寸法・入力からframe commitまでを測定する。実写真の印象や肉眼のバンディング評価と合成検査を混同しない。

## UI寸法（実装前に確定）
Claude最終参照は`docs/design/loupe-tone-curve.html`。パネルは左右8dp/下8dp/高さ264dp/内側8dp/角丸16dp/背景#B8101012、1dpの薄い枠。上段48dp、行間4dp、中段144dp、行間4dp、ロールオフ48dp。編集対象は均等5列＋右48dpリセット。右列152dp（入力/出力の各行48dp、ラベルは文字幅、数値欄64dp、下行の48dpアイコン3個＋4dp間隔）。グラフは残り幅、内側8dp。入力/出力は小数1桁表示、内部は丸めない。選択点なしでは値欄と削除を無効化。点選択は48dp矩形の中で最短距離を優先、空白のタップで追加。物理キーの矢印で選択点の入力/出力、PageUp/Downで選択切替、Insertで中点追加、Deleteで削除。読み上げ用に選択/追加/削除/入力増減/出力増減の明示操作を用意する。2本指は編集中の曲線/ロールオフを戻し、写真の拡大へ引き継ぐ。

数値欄の未確定入力は編集開始時のbank/点/不変curveに結び付ける。点・bank・画面の選択変更では元の点へ確定する。削除・リセット・Undo/Redoなどcurveを置き換える操作では未確定入力を破棄する。外部のモデル置換でも所有curveが変われば破棄し、置換後の別の点へ流用しない。表示文字列を未編集の座標へ再適用しない。
