# タグの閲覧と基準を教える操作

詳細の参照は[Confidence UI](design/loupe-tag-confidence.html)、学習と表示の契約は[タグConfidence](tag-confidence-contract.md)。4列の写真、タグ付き/該当しないの切替、写真を解析、基準を教える、写真を追加/一括訂正/その他を持つ。アルバムとカメラの範囲を明示する。閾値と学習状態は下部のスクロール可能な操作パネルに置く。

閲覧はタップで拡大、左右は移動のみ。タグを付ける/外すを保存した後も同じ写真に留まる。外す操作はEXCLUDEDとし、再推定の表示を抑える。既存のUNDECIDED履歴も抑制を保持する。手動判断が推定より優先される。

基準を教える画面では含めない・保留・含めるを選び、直前の判断を取り消せる。開始時の未判断候補数を進捗の分母とする。保存中は操作とBackを止め、成功後だけ進む。保存失敗は操作の印で示し、同じ写真と判断を保って再試行できる。スワイプで判断や候補移動を行わない。

閾値の変更では保存済みスコアから一覧と件数だけを更新する。判断の保存後はキャッシュ済み特徴で学習し直す。計算中・結果用意済みは前回の結果の印を出し、一覧を表示し直すまで現在の写真と集合を保つ。新しい特徴の抽出は写真を解析でのみ始める。中止で未確定処理を止め、完成済み結果は保持する。

## 一覧での複数選択

一括訂正または長押しで複数写真を選ぶ。タグ付き/推定の一覧では該当しないにする、追加/該当しないの一覧ではタグ付きにする。戻るは未保存の選択だけを解除する。判断は一つのトランザクションで保存し、一部だけ反映しない。失敗時は選択を残し再試行できる。成功後は選択を解除し、一覧位置を可能な範囲で保持する。原本と他タグは変更しない。
