# 写真移動前の照合進捗

## 目的と要件

[Issue #172](https://github.com/ktnyt/Loupe/issues/172)で報告された取り込み済み写真の内容照合では、固定文言だけでは処理が進んでいるか分からない。移動を検討している利用者が、照合の工程、処理済みの枚数と読み取り量を把握し、必要なら確認を中止できるようにする。

[旧取り込み写真の移動前確認](legacy-time-move-contract.md)の原本アクセス、全量SHA-256、履歴とE2の根拠、排他制御、移動の明示確認を適用する。確認は読み取り専用とし、写真・履歴・移動ジャーナル・E2記録を書き換えない。

## 表示と操作の契約

- 保存先画面で「取り込み済みの写真を移動」を押すと「照合する写真を調べています」と不定進捗を表示する。対象が確定し、内容の照合が必要な写真があれば「バックアップと写真の内容を照合中」に切り替える。
- 照合中は実際の読取済み容量と対象容量に加え、処理済み枚数と対象枚数、照合一致と対象外の内訳を表示する。対象には内容照合が必要な旧取り込み写真だけを数え、既に移動可能な写真と準備段階で除外した項目は含めない。成否が確定すると処理済み枚数が増える。
- バーは実際の読み取りに合わせて更新する。一致しなかった原本の不足分を読み取り済みとみなさず、余分に読めた容量も読取量として保持する。読み取り終盤に確認が残っている場合や対象外項目がある場合は、バーを最大値にしない。結果が確定すると既存の移動確認、対象なし、または失敗の表示へ進む。
- 準備・照合中は「まだ移動していません」と「確認を中止」を表示する。中止を選ぶと「写真の確認を中止しています」と表示し、原本の読み取り処理が終了したら同じ画面からやり直せる。画面を離れる場合も照合を中止し、古い依頼の進捗と結果を表示しない。移動の開始操作は既存の確認画面にある。
- [Material 3 UI 契約](material3-ui.md)に沿って、線形進捗バーと折り返せるテキストを保存先画面のスクロール領域に配置する。中止には48dp以上の操作領域を確保する。工程名は読み上げ可能とし、更新頻度の高い枚数や容量を自動で読み上げない。

## 実装と検証の契約

- workerは依頼ごとに表示用の最新集計を保持する。画面は約250ms間隔で取り込み、次の読み取りを待つ間も、読み取れた分を表示する。キャンセルや再試行後、非表示の画面には反映しない。集計は移動を許可する根拠に含めない。
- 診断は操作開始から照合結果の表示までを集計し、対象枚数、実際の読取量、対象容量と経過時間を記録する。個別のファイル名やパスを追加せず、コピーの計測とは区別する。
- 合成データで途中の読取量、正常・短い・長い原本、除外数、中止と再試行、画面を離れたときの古い進捗や結果の破棄を確かめる。通常幅・文字倍率1.0と320dp・文字倍率1.3のAndroid画面を記録し、進捗の読みやすさ、画面内の配置、中止操作、読み上げ用表示を確認する。
