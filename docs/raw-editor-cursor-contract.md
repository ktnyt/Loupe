# 現像のカーソル操作と写真の移動

Issue #59。基点main `9490bba`。目的は、調整点を常に把握し、写真を観察する移動と現像値の変更を意図どおりに分けること。#56のガイド契約と#55の原寸契約のうち、ヒット・倍率・現在点表示を以下へ更新する。利用者指定を契約へ具体化し、[Claude参照HTML](design/loupe-raw-editor-cursor-navigation.html)を保存した。本体0.21.0/142・実験0.4.0/6へ実装・導入し、合成実機で操作を確認済み。

## 合意した要件と具体化

- 面とスライダーのカーソルを見せ、カーソルをつかんだ時だけ値を変える。補助行のかすみ/コントラストも対象。
- カーソル以外の単指ドラッグは写真をパンし、ダブルタップは原寸100%→原寸150%→全体表示を循環する。
- カーソル上のダブルタップは、既存の両軸/片軸初期化を維持する具体化。写真上に説明・数値を追加しない。

## 不変条件

- 面・右・下の現在点は常時半透明で描画する。面の枠/格子/基準線とレールだけを操作開始120msで表示し、終了3秒後から400msで消す。表示の変化は現像値を変えない。
- DOWN時だけ現在点の中心を基準に最小48dpの操作領域を判定する。値は開始値に対する指の移動量で変わり、つかむ位置で飛ばない。面は両軸、右/下/補助スライダーは自分の軸だけ。
- 空白から始まった指は途中で点を横切っても調整へ変わらない。開始時の操作分類を指が離れるまで保持する。タブ切替・無効化・detach・背景化で古いジェスチャー/遅延表示を取り消す。
- 空白のドラッグ/ダブルタップは写真のviewportだけを変え、編集値・Mono/MAXを変えない。カーソルのダブルタップは対象値だけdefaultへ戻す。WBは撮影時基準0/0、曲線は0.5/0.5。
- 2本目の指で、途中の単指調整を開始前へ戻し写真ピンチへ渡す。全て離すまで残った指で調整を再開しない。単指CANCELは現在値を保つが、遅延初期化を発火しない。
- AX/キーボードは従来の値変更と明示初期化を保持し、物理カーソルのヒット制限を読み上げ操作へ適用しない。

## 倍率と事前条件

- 写真の有効原寸とView寸法が既知であること。原寸100%は元画像1画素=画面物理1画素、150%は1.5画素。fitは従来の全体表示で、通常はfit→100→150→fit。
- 100→150は見ている画像内の中心を保ち、画像境界で必要なclampだけ行う。fitで移動を中央へ戻す。任意のピンチ位置からは次のダブルタップで100%へ進める。
- ピンチ上限は原寸150%とfitの大きい方、下限は100%とfitの小さい方。小画像も実画素の100/150を表し、fitとの倍率一致でも循環を停止しない。
- 保存・読込中は現像操作と写真操作を開始しない。原寸準備中・失敗時の表示と再試行、入力コピー/キャッシュ所有、同一shader/世代管理/原寸JPEG保存の契約は変更しない。
