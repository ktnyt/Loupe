# 同じUSBカードリーダーの2枚のカード間で写真を取り込む（#166）

## 対象と目的

USBカードリーダーに入れた取り込み元のSDカードから、同じリーダーに入れた保存先カードへ写真を取り込む。Androidが2枚を別のボリュームとしてマウントし、取り込み元の原本を読み取れる場合に実行できる。カードやスロットと、MediaStoreのボリュームの対応をUSB機器名やスロットの順序から推定しない。

## 操作と判定

- 外部ストレージが保存先で、汎用USBマスストレージ機器がつながっている場合は、Androidで開ける取り込み元を使う。設定済みのDCIMフォルダが開ければ、そのフォルダから取り込む。開けるフォルダがなければ選択を案内する。USB接続時の自動起動では、SDの自動取り込みが実際にマウントを監視している場合はその通知に処理を任せ、それ以外では未確認の組み合わせの確認を開く。確認済みの元と先で再接続した場合は取り込み画面を開き、開始ボタンの操作を待つ。直接USB読み取りや内部ストレージへの自動切り替えは行わない。
- フォルダの選択、権限確認、画面の再作成をまたいでも、開始時に選ばれていた保存先を保持する。USB接続による起動と、マウントを契機とした自動取り込みにも適用する。処理開始時に取り込みの排他を取得し、選択中の保存先が変わっていないことと書き込み可能なことを確認する。
- SDからの手動取り込みでは、初回に取り込み元と保存先を表示し、JPEGとRAWのうち選んだ形式を取り込む。サービスが要求を受理したときに、取り込み元のフォルダと保存先の組み合わせごとに形式を記憶する。登録済みフォルダと同じ保存先での手動開始と長押しでは確認を省く。フォルダ選択から登録し直す場合は開始前に確認する。SD取り込み設定の「形式を選んで取り込む」で再選択できる。フォルダやカード、保存先を変えた場合は、変更後の組み合わせに対応する選択を使う。動画の取り込みには対応していないことを、動画が選ばれていた場合は開始前に案内する。フォルダの照合に失敗した場合は、以前の取り込み元の設定を保持する。
- 別のカードへの取り込みでは、取り込み元のExternalStorageProviderのUUIDを、読み取り可能な着脱式ストレージのうち1つだけに照合する。保存先と同じボリューム、未接続、または元のボリュームを確認できない場合は、保存処理を始めずに選び直しを案内する。個々のファイルの前にもフォルダの権限とMediaStoreの実ボリュームを照合する。取り込み済みの判定や再試行で原本の読み取りを省ける場合も照合する。
- 通常のフォルダ指定による取り込み、Wi-Fi、USB PTP、内部ストレージに保存する直接USB取り込みは、既存の操作を維持する。外部ストレージを選んだ状態で直接USBマスストレージを使う場合は、Androidのドライバーを切り離さずにアクセスできる場合だけ読み取る。インターフェースを確保できないときは、フォルダ指定を案内する。ドライバーを強制的に切り離して再試行しない。

- 別カードへの取り込みで写真のMediaStore URIを取得できない場合は、Androidから `IllegalArgumentException` が返ったときも、取り込み元のカードとフォルダの権限を確認する。Loupeから照会できる同じカードの写真一覧をフォルダと名前で絞り、該当する行が返らなかった場合に、カードを接続したまま待って再試行するよう案内する。照会に失敗した場合や写真の情報が一致しない場合は、原本を確認できない旨を案内する。

## 原本と保存結果

元のカードからは読み取るだけとし、写真原本は削除しない。アクセス権限、ファイルの原本確認、写真のSHA-256、取り込み履歴による重複判定、公開前の読み戻しと既存の復旧処理を維持する。選んだ保存先に書き込めなくなった場合は処理を止める。アクセス権限の不足、取り込み元のフォルダが開けない状態、保存先が変わった状態、同じカードを選んだ状態を区別して案内する。

## 検証

合成データで、USBとフォルダの選択、別カードと同じカードの判定、保存先変更、マウント解除、読み取り許可の不足、原本の途中読み取りの失敗を確認する。実機では2枚が同時にマウントされた状態で合成写真を取り込み、保存先の実ボリュームと全バイト、元のファイルの保持、同じ写真の再取り込み時の重複判定を確認する。2枚目がAndroidから見えない状態は、カード間取り込みの成功として扱わない。

## 対応リーダーでのUSB直接取り込み

SDカード取り込み設定の「USBでmicroSDへ直接保存」から手動で開始する。対象は、Android 16のXiaomi `dada` と、SD・microSDの両方を同時に認識するAnker A83D1。開始にはShizuku、USBの利用許可、取り込み元SDのDCIMの登録と読み取り許可、microSDの保存先選択が必要。直接取り込むJPEG・RAWの形式はUSB取り込み設定に従う。両カードがexFATで、Androidによる取り外しとUSBスロットの照合が成立したときに続ける。

ShizukuはAndroidから両カードを安全に取り外し、LoupeがUSBを閉じた後にAndroidへ戻す。LoupeはSDを読み取り専用で開く。AndroidがmicroSD上で確保した未公開ファイルの連続領域だけをUSBの書き込み対象にする。ファイルの内容は上限付きのバッファで転送し、スマホ本体に写真の一時コピーを作らない。照合に通らないパーティション、割り当て、履歴、接続状態では処理を止める。

USBとAndroidの両方から読み戻して元のSHA-256と一致した写真を公開し、取り込み履歴を確定する。旧CameraSyncの保存ファイルは実際のSHA-256で照合し、上限内のヘッダーで既知のOffsetTime補正だけが異なる場合も、残りの全バイトが一致すれば引き継ぐ。直接保存する新規写真は原本のバイト列を保持する。未確定の写真は公開しない。USBを閉じたこと、書き込みの確定、Androidへの返却を確認できない場合は、未確定の記録を残して利用者にカードリーダーの挿し直しを案内する。

検証では、合成USBとexFATで書き込み範囲、保存前後のハッシュ、失敗時の復帰を確認する。Androidの計測テストで、未公開行の確保と既存の取り込み履歴への反映を確認する。配布前には対象リーダーとAndroidで書き込みと復帰の一連の動作を行い、元のSDとmicroSDの既存ファイルを保持することを確認する。
