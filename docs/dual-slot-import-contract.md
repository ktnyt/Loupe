# 同じUSBカードリーダーの2枚のカード間で写真を取り込む（#166）

## 対象と目的

USBカードリーダーに入れた取り込み元のSDカードから、同じリーダーに入れた保存先カードへ写真を取り込む。Androidが2枚を別のボリュームとしてマウントし、取り込み元の原本を読み取れる場合に実行できる。カードやスロットと、MediaStoreのボリュームの対応をUSB機器名やスロットの順序から推定しない。

## 操作と判定

- 外部ストレージが保存先で、汎用USBマスストレージ機器がつながっている場合は、Androidで開ける取り込み元を使う。設定済みのDCIMフォルダが開ければ、そのフォルダから取り込む。開けるフォルダがなければ選択を案内する。USB接続時の自動起動では、SDの自動取り込みが実際にマウントを監視している場合はその通知に処理を任せ、それ以外では取り込み元と保存先の確認を開く。直接USB読み取りや内部ストレージへの自動切り替えは行わない。
- フォルダの選択、権限確認、画面の再作成をまたいでも、開始時に選ばれていた保存先を保持する。USB接続による起動と、マウントを契機とした自動取り込みにも適用する。処理開始時に取り込みの排他を取得し、選択中の保存先が変わっていないことと書き込み可能なことを確認する。
- 別カードへの手動取り込みでは、取り込み元と保存先の名称とボリューム識別子を表示し、JPEGとRAWのうち選んだ種類を取り込む。動画の取り込みには対応していないことを、動画が選ばれていた場合は開始前に案内する。フォルダの照合に失敗した場合は、以前の取り込み元の設定を保持する。
- 別のカードへの取り込みでは、取り込み元のExternalStorageProviderのUUIDを、読み取り可能な着脱式ストレージのうち1つだけに照合する。保存先と同じボリューム、未接続、または元のボリュームを確認できない場合は、保存処理を始めずに選び直しを案内する。個々のファイルの前にもフォルダの権限とMediaStoreの実ボリュームを照合する。取り込み済みの判定や再試行で原本の読み取りを省ける場合も照合する。
- 通常のフォルダ指定による取り込み、Wi-Fi、USB PTP、内部ストレージに保存する直接USB取り込みは、既存の操作を維持する。外部ストレージを選んだ状態で直接USBマスストレージを使う場合は、Androidのドライバーを切り離さずにアクセスできる場合だけ読み取る。インターフェースを確保できないときは、フォルダ指定を案内する。ドライバーを強制的に切り離して再試行しない。

## 原本と保存結果

元のカードからは読み取るだけとし、写真原本は削除しない。アクセス権限、ファイルの原本確認、写真のSHA-256、取り込み履歴による重複判定、公開前の読み戻しと既存の復旧処理を維持する。選んだ保存先に書き込めなくなった場合は処理を止める。アクセス権限の不足、取り込み元のフォルダが開けない状態、保存先が変わった状態、同じカードを選んだ状態を区別して案内する。

## 検証

合成データで、USBとフォルダの選択、別カードと同じカードの判定、保存先変更、マウント解除、読み取り許可の不足、原本の途中読み取りの失敗を確認する。実機では2枚が同時にマウントされた状態で合成写真を取り込み、保存先の実ボリュームと全バイト、元のファイルの保持、同じ写真の再取り込み時の重複判定を確認する。2枚目がAndroidから見えない状態は、カード間取り込みの成功として扱わない。
