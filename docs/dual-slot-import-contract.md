# 同じUSBカードリーダーの2枚のカード間で写真を取り込む（#166）

## 対象と目的

USBカードリーダーに入れた取り込み元のSDカードから、同じリーダーに入れた保存先カードへ写真を取り込む。Androidが2枚を別のボリュームとしてマウントし、取り込み元のオリジナルを読み取れる場合に実行できる。カードやスロットと、MediaStoreのボリュームの対応をUSB機器名やスロットの順序から推定しない。

## 操作と判定

- 外部ストレージが保存先で、汎用USBマスストレージ機器がつながっている場合は、Androidで開ける取り込み元を使う。設定済みのDCIMフォルダが開ければ、そのフォルダから取り込む。開けるフォルダがなければ選択を案内する。USB接続時の自動起動では、SDの自動取り込みが実際にマウントを監視している場合はその通知に処理を任せ、それ以外では未確認の組み合わせの確認を開く。確認済みの元と先で再接続した場合は取り込み画面を開き、開始ボタンの操作を待つ。直接USB読み取りや内部ストレージへの自動切り替えは行わない。
- フォルダの選択、権限確認、画面の再作成をまたいでも、開始時に選ばれていた保存先を保持する。USB接続による起動と、マウントを契機とした自動取り込みにも適用する。処理開始時に取り込みの排他を取得し、選択中の保存先が変わっていないことと書き込み可能なことを確認する。
- SDからの手動取り込みでは、初回に取り込み元と保存先を表示し、JPEGとRAWのうち選んだ形式を取り込む。サービスが要求を受理したときに、取り込み元のフォルダと保存先の組み合わせごとに形式を記憶する。登録済みフォルダと同じ保存先での手動開始と長押しでは確認を省く。フォルダ選択から登録し直す場合は開始前に確認する。SD取り込み設定の「形式を選んで取り込む」で再選択できる。フォルダやカード、保存先を変えた場合は、変更後の組み合わせに対応する選択を使う。動画の取り込みには対応していないことを、動画が選ばれていた場合は開始前に案内する。フォルダの照合に失敗した場合は、以前の取り込み元の設定を保持する。
- 別のカードへの取り込みでは、取り込み元のExternalStorageProviderのUUIDを、読み取り可能な着脱式ストレージのうち1つだけに照合する。保存先と同じボリューム、未接続、または元のボリュームを確認できない場合は、保存処理を始めずに選び直しを案内する。個々のファイルの前にもフォルダの権限とMediaStoreの実ボリュームを照合する。取り込み済みの判定や再試行でオリジナルの読み取りを省ける場合も照合する。
- 通常のフォルダ指定による取り込み、Wi-Fi、USB PTP、内部ストレージに保存する直接USB取り込みは、既存の操作を維持する。外部ストレージを選んだ状態で直接USBマスストレージを使う場合は、Androidのドライバーを切り離さずにアクセスできる場合だけ読み取る。インターフェースを確保できないときは、フォルダ指定を案内する。ドライバーを強制的に切り離して再試行しない。

- 別カードへの取り込みで写真のMediaStore URIを取得できない場合は、Androidから `IllegalArgumentException` が返ったときも、取り込み元のカードとフォルダの権限を確認する。Loupeから照会できる同じカードの写真一覧をフォルダと名前で絞り、該当する行が返らなかった場合に、カードを接続したまま待って再試行するよう案内する。照会に失敗した場合や写真の情報が一致しない場合は、オリジナルを確認できない旨を案内する。

## カードの再認識

対応する機器では、取り込み画面を開いたときと、取り込みタブを長押ししたときに、リーダーを一度だけ再認識する。画面を開いたときは、再認識した取り込み元を表示する。長押しでは、再認識後にオリジナルを残す取り込みへ進む。もう一度試すときは「SDカードを再認識」を押す。マウント通知や画面の復帰だけでは再認識を始めず、取り込みや移動が受理済みの場合も行わない。再認識後は指定した保存先と現在の取り込み元を照合し、未登録の元カードはフォルダの選択を案内する。[再認識の契約](sd-usb-reprobe.md)

## オリジナルと保存結果

元のカードからは読み取るだけとし、写真オリジナルは削除しない。アクセス権限、ファイルのオリジナル確認、写真のSHA-256、取り込み履歴による重複判定、公開前の読み戻しと既存の復旧処理を維持する。選んだ保存先に書き込めなくなった場合は処理を止める。アクセス権限の不足、取り込み元のフォルダが開けない状態、保存先が変わった状態、同じカードを選んだ状態を区別して案内する。

## 検証

合成データで、USBとフォルダの選択、別カードと同じカードの判定、保存先変更、マウント解除、読み取り許可の不足、オリジナルの途中読み取りの失敗を確認する。実機では2枚が同時にマウントされた状態で合成写真を取り込み、保存先の実ボリュームと全バイト、元のファイルの保持、同じ写真の再取り込み時の重複判定を確認する。2枚目がAndroidから見えない状態は、カード間取り込みの成功として扱わない。
