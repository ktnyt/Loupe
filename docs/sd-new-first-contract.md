# #128 SD取り込みの操作と待ち時間

対象は0.31.51（mainの0c5b44b）以降のSD取り込み。SDからmicroSDへの取り込みと登録待ちの処理は[カード交換の契約](sd-source-swap-contract.md)を引き継ぐ。

## SDの開始と設定

- 文脈。接続状況に応じた上部の開始ボタンと、SD専用欄の開始ボタンが、同じUSBリーダーで外部カードに保存するときに同じSD取り込みへ進む。設定が画面に展開されているため、開始と設定の所在が分かりにくい。
- 目的。普段は一つの開始ボタンでSDから取り込み、取り込み元やオプションを変更したいときに設定を開ける。
- 要件。SD欄に開始とペンの設定ボタンを置く。同じSD処理を呼ぶ取り込み状況欄の開始ボタンを、その構成では表示しない。通常のカメラUSB操作とWi-Fiの操作は引き続きそれぞれの入口で使える。ライブラリの長押しでSDから開始できる。
- 契約。設定を開くだけでは再登録・取り込み・自動取り込みの変更をしない。フォルダの選択と登録確認、選択取消、内容確認、自動取り込み、権限確認、進捗の中止と再試行を維持する。同じUSBリーダーで外部へ保存する確認では取り込み元と先、既存の写真形式の初期選択を示し、JPEGとRAWを選び直せる。原本は残る。
- 画面。既存のWi-Fi欄と同じペンの配置を使い、読み上げ名は「SDカード取り込み設定」とする。詳細はスクロール可能なMaterialの画面に収め、閉じる・戻るで取り込み画面へ戻れる。設定・取り込みが使用できない状態は、操作が重ならないよう以前の制約を維持する。320dp・文字1.3倍と通常幅で操作を確認する。
