# 単写の1位指定

目的は単写をお気に入りのように選び、後から1位フィルターで見つけられること。写真ビューアーの星の操作で指定・解除する。動画と連写内の写真にはこの操作を出さず、連写は既存の順位指定を使う。

## 契約

- 単写は初期状態では未指定。明示指定だけを1位として扱う。
- 1位フィルター・順位決定済みには指定済み単写、順位が未決定には未指定単写を含める。すべての一覧には両方を表示する。
- 一覧の1位バッジと共有シートの1位表示も同じ保存状態を読む。
- 「連写は1位だけ共有」の対象は従来どおり連写。明示選択した単写は指定の有無にかかわらず共有できる。
- 既存のrankings設定に独立したsingle-best-v1キーを使い、写真のArchiveStore.keyのdigestに対応する状態を保存する。連写journal、原本、タグ、API設定は変えない。
- 保存中は操作を無効にし、同期commit成功後にだけ画面の状態を変える。失敗時は保存前の値に戻し、再試行できる。読み込み失敗時は未指定で上書きしない。
- Material 3の既存ビューアー操作部へ配置する。指定済みは星とgold色、checked/stateDescription、解除の操作名で示す。幅は指定・解除の両ラベルを使って測り、切替による並び替えを防ぐ。

実装前の要件・判断と検証記録は[issue #109](https://github.com/ktnyt/Loupe/issues/109)に置く。
