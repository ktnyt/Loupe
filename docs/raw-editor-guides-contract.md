# 現像ガイドの一時表示と初期化

Issue #56。基点main 7c5bab8。原寸処理#55とは別の操作UIの契約。従来の常時非表示を、利用者の訂正に合わせて置き換える。実装・ビルド・合成実機と独立UI/Cold/Security Reviewを実施済み。本体0.19.1/140をデータ保持で導入し、内蔵現像の入口・Mono/状態復元・別保存/中止・原本不変の合成実機回帰を確認済み。

## 目的・要件

写真を主役に保ち、触っている面と片軸スライダーを必要な間だけ見せる。面・右・下の操作位置と寸法、7タブと補助行、ピンチ、Mono/MAX、原本と保存処理は保持する。ダブルタップで面の両軸、各スライダーではその軸だけ初期値に戻せる。

## 契約

- 面は1dpの白35%枠と黒25%の補助線、白12%の格子、白32%の中央基準線。右/下は2dp・白35%のレールと現在値の点を示す。写真上の軸名/数値札や面の塗りは追加しない。外観の正本は[Claude参照](design/loupe-raw-editor-guides.html)。
- 最初の操作前はカーソルだけ。単指操作でガイドを120msで表示し、指が離れるまで保持する。離して3秒後から400msでフェードする。新しい操作は待機とフェードを取り消して再表示する。フェード後も半透明カーソルとヒット領域を保持する。
- 面のダブルタップは対応するx/y値だけをRawEditStateのdefaultへ戻す。右帯はyだけ、下帯はxだけ。かすみ/コントラストの独立スライダーは自分の値だけを戻す。WBのdefaultは撮影時WBからの相対調整0/0、曲線の点は0.5/0.5。他のパラメーター・Mono/MAXは変えない。
- ダブルタップ後の同じ指のUPで値を触点へ書き戻さない。ドラッグや長押し、時間/距離の離れた2タップは初期化しない。Androidのタッチ/ダブルタップ判定の許容値を使う。
- 2本目の指でピンチに切り替えたら、当該単指操作開始前の値へ戻し、初期化も取り消す。ガイドを消し、残った指がパラメーター操作を再開しない現行契約を保つ。
- キーボードと読み上げ向けの初期化操作を用意し、物理ダブルタップ判定とTalkBackの操作を混同しない。フォーカス枠・現在値の読み上げ名を維持する。
- タブの再構築・view離脱・Activity背景化/終了では表示animationと遅延callbackを解除する。古いタブから再表示しない。保存中/読込中の無効状態で編集値を変えない。表示タイミングだけでは編集値や写真描画の世代を進めない。

## 検証

合成実機でガイドの画素/時間/保持/再操作/消去、全7タブdefaultと固定位置、両軸/片軸/補助slider reset、WB0/curve.5、最終UP変位の2回帰、ドラッグ/長押し/遠いtapの除外、Mono/MAX保持、ピンチ取消、AX/Delete、tab/background cleanupを確認済み。通常window/文字1.0・高さ640dp/文字1.3の撮影を行い、写真/カーソル/選択線の実Window画素を同時確認した14枚を独立レビュー済み。ガイド4状態と参照形状も確認。OS inset/viewport/合成素材/フォント条件が異なるため全画素の厳密一致とは扱わない。Cold/Securityの必須指摘は解消済み。本体0.19.1/140の合成編集/保存/状態復元/原本保全を確認済み。実指操作、実TalkBack音声、実写真上のガイド視認性は未確認。比較資料は[参照と実機](design/loupe56-comparison-drag.png)、[4状態](design/loupe56-states-matrix.png)、[画素確認済み7タブ](design/loupe56-tabs-confirmed.png)。
