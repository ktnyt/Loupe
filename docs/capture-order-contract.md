# 閲覧一覧の撮影日時

## 目的と要件

MediaStoreの撮影日時が欠けていても、写真から読める撮影日時で一覧と連写の時系列をそろえる。既存写真の原本・順位・タグは保持する。

## 契約

- 閲覧インデックスは、保存済みまたは写真から読み取った正のEXIF撮影日時を優先する。撮影日時が読めない写真は従来の日時を使う。
- 補正は閲覧用のPhotoのコピーに適用し、並べ替えてから連写をまとめる。連写の検出を無効にしていても撮影日時を反映する。
- インデックスの署名に日時解釈の版を含め、既存インデックスを更新する。
- MediaStore、写真原本、バックアップや削除の入力を書き換えない。写真のキーに撮影日時を含めず、順位・タグとの対応を維持する。
- 元のメタデータにサブ秒がない場合、同じ秒の連写内の厳密な撮影順を保証しない。

新規カメラ取り込み時に写真のメタデータを補正する機能とは別に扱う。
