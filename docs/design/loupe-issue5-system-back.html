Loupe Issue #5 — 独自の戻るを廃止して、Android標準のBackへ統一

写真はダミーの色面です。Aは dock の部品の旧／新の比較、Bは画面のつながりの模擬です。画面の外にある［Android Back］は検証用で、アプリの中に説明や代わりのボタンは足していません。タグ・クラウド・同期の設定は簡略な状態遷移です。

幅 文字

A. dock の部品（旧：戻るあり／新：戻るなし）

画面

旧 消す操作は赤い点線

新 #5

B. 画面のつながり（標準Backの模擬）

1. 消す操作と残す操作

画面消す（専用のナビ）残す
個別アルバムの一覧の dock戻る選択・タグ・その他
連写の詳細の4操作の dock戻る前の写真・次の写真・拡大（主操作の全幅ボタンと、ほかの行は変えない）
写真の詳細戻る／比較に戻る共有・その他
比較・結果の dock の末尾連写一覧／選択へ戻る取り消し・その他。すべての順位方式の比較中だけ、同じ順位も残す
タグの画面写真に戻る／タグ一覧に戻る／タグに戻る／一覧に戻るそれ以外の既存の操作
クラウド・同期の設定戻る（dock がこれだけなら dock ごと消す）中身の項目
ナビではないので残す選択を終了・取り消し・拡大を戻す・確認ダイアログの否定操作（このあと「キャンセル」に統一）

2. 標準Backの順番

今いる場所Back
ダイアログ・シートキャンセル（閉じるだけ。中身は変えない）
保存中（busy）既存どおり戻らない。データはそのまま保つ
写真の拡大（写真の詳細）開いた元へ：比較・連写の詳細・一覧
比較・結果開いた元へ：連写の詳細、または共有の選択（順位の進み具合と選択は保つ）
連写の詳細元の一覧へ（スクロールの位置を保つ）
個別アルバム呼び出し元のルート（アルバム／すべての写真）へ
選択中の一覧まず選択を終了する（選択はそこで終わる。画面は移らない）
ルートOSへ（アプリを離れる）
タグ写真 → 同じ絞り込み・同じ位置の一覧 → タグ詳細 → タグ一覧 → 呼び出し元。タグの写真一覧の選択中は、まず選択を終了
クラウド・同期の設定呼び出し元へ（同期の設定 → クラウド → 呼び出し元）。ログインや同期の設定は変えない
  • 一覧のスクロールの位置は、戻ったときにそのまま復元する。
  • タグの推論（#1）と、タグの編集・保存の仕様は変えない。

3. dock の列

  • 戻るを消して空いた列は、残りの操作で均等に分ける。空の戻るの枠は残さない。
  • 比較と連写の詳細の dock は、#9の列の決め方をそのまま使う（必要なセル幅 = 最も長いラベルの文字幅 + 12dp。同じ幅のセルに全部入る最大の列数。足りないときだけ複数行）。
  • dock の値は#9と同じ：背景 #19191B、全周8dp、ボタン64dp以上、13sp（1.3倍でも縮めない）、上に24dpのアイコンの枠（26dpの描画基準）、間隔4dp、全周6dp、行の箱24dp。
  • 取り消しの読み上げ名は「直前の操作を取り消す」のまま。

4. 確認ダイアログ

  • 安全のための確認（再ソート・ソート方式の変更など）はそのまま残す。
  • 否定の操作の名前を「キャンセル」に統一する案（#7で「戻る」にしていた確認も「キャンセル」に）。Backはこの「キャンセル」と同じ動き。

5. 範囲外

  • 写真の全体表示、ほかの操作の再設計、全体の配置（#8）。
  • アプリの中に、Backの説明や代わりのボタンは足さない。
  • このHTMLのタグ・クラウド・同期の設定は簡略な状態遷移で、画面の中身は実際と異なる。
