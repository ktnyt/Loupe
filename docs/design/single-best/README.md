# 単写の1位指定のAndroid検証

現行契約は[単写の1位指定](../../single-best.md)と[Material 3 UI契約](../../material3-ui.md)。本フォルダーはAndroid実装の検証記録であり、視覚設計の原典ではない。

- 比較元: `7082ff7`。production sourceは無変更、同じ合成写真を表示するcapture用instrumentationだけを追加して取得したbaseline画像。
- 変更後: `40d0d29`。`single-best-{width}-{font}-{off,on,filter}.png`。
- 対象: 専用 `emulator-5580`、縦画面。400dp/font 1.0、320dp/font 1.3。生成したJPEGと検査専用SharedPreferencesを使用し、写真原本や利用者の順位を書き換えない。
- 操作: 初期未指定→指定→保存後状態→Back→1位/未決定/決定済みフィルター→再表示→解除→1位から消えることを確認。別単写と既存連写journalの不変、連写メンバーに単写ボタンがないことも確認。
- プログラム検査: checkable/checked、保存中の無効化、48dp以上の幅・64dp以上の高さ、切替前後の位置とサイズ、文字幅に応じた段組みを確認。
- 追加のAndroid検査: actionsをlatchで待たせ、保存中のBack・再表示・1位フィルターへの移動後に現在画面が更新されること、古い期待値の保存拒否後の再試行を確認した。commit falseと読み込み例外を注入し、旧状態の保持と再試行、読み込み再試行だけでは指定を書かないことを検査した。最終400dp/font 1.0では初期readと最初のretryを2回だけ失敗させた回復と、読み込み中/保存中のAX状態もPASS。
- 保存のhost検査: 未指定、指定・解除・再読込、別写真/連写の分離、古い期待値の拒否、メモリ先行更新を伴うcommit失敗のrollback、破損値の拒否。
- 独立UIレビュー: 変更前2枚と変更後6枚、操作記録を評価。エミュレータ証拠の範囲でブロッキング指摘なし。400dpで操作が1段から2段となり写真領域の位置が変わるが、操作と写真の分離を確認。

物理端末、TalkBackの音声、process再起動、OTA更新後のAPK照合は未実施。保存失敗は注入した条件でのUI検査であり、実端末の空き容量不足の再現ではない。共有シートの1位表示と動画は今回のcapture検査の対象外。実機確認の合格を示す記録ではない。

工程・失敗・レビューの詳細は[issue #109](https://github.com/ktnyt/Loupe/issues/109)に記録する。

既存 `viewer-screen` の全回帰は単写8操作の配置・写真表示・Backを通過後、従来の拡大ボタンのAX状態検査で失敗した。この回帰全体を合格とは扱わず、変更前から不変のzoom実装に関する独立課題を[issue #110](https://github.com/ktnyt/Loupe/issues/110)へ分離した。
