3. 読み上げ（TalkBack）

  • タブバーはタブの一覧として扱う（HTMLでは role="tablist"、Androidでは TabLayout 相当、または Role.Tab と selected）。
  • 読み上げ名は見えている文字と同じ：「すべての写真」「アルバム」。下線は読み上げない。
  • 選択中の状態は「選択済み」として読む（Android標準の読み上げ。例：「選択済み、アルバム、タブ、2個中2個目」）。新しい文言は足さない。
  • 選択中（写真を選んでいる間）は2つのタブとも「無効」と読まれる（enabled = false）。
  • タブを切り替えたときに、画面の説明を読み上げることはしない。

4. 状態の保持

保持するもの内容
一覧の位置タブごとに、先頭に見えている項目の番号と、その上端のずれ（dp）を持つ（Composeなら firstVisibleItemIndex・firstVisibleItemScrollOffset）。タブを戻したとき、子画面から戻ったときに、そのまま復元する
すべての写真のフィルターカメラのフィルターと順位のフィルター（すべて／1位／順位が未決定の連写）。タブを切り替えても、子画面から戻っても変えない
選択タブの切り替えで選択は消さない（そもそも選択中はタブを押せない）。選択の終了は、利用者の「選択を終了」か既存のBackのときだけ
中身が変わったとき先頭の項目がなくなったら、近い番号の項目から表示する（位置を0に戻さない）
フィルターを変えたとき位置は保持した番号で復元する。絞り込みで一覧が短くなり、その番号の項目がないときは、いちばん近い項目にそろえる（既存のフィルター変更時の挙動があればそちらを優先・要確認）

5. 戻る（Back）

場面Android標準のBack
ルート（すべての写真・アルバム）アプリを離れる。別のタブへは戻さない（どちらのタブにいても同じ）
子画面（個別アルバム・連写・写真）元のタブの一覧へ戻る。位置とフィルターはそのまま。共通タブが再び表示される
選択中既存の挙動のまま（選択を終了する）。終了したらタブを有効に戻す
シート（その他など）を開いているとき既存のまま（シートを閉じる）
子画面の独自の［戻る］今回は残す（全廃は#5）。動きは標準のBackと同じ

6. 一覧が空・読み込み中・エラーのとき

  • タブはいつも有効で、押せる（選択中を除く）。どの状態でも、もう一方のタブへ移れる。
  • 一覧の中身の表示は既存のまま。このHTMLでは、空＝既存の空の表示の代わり、読み込み＝文字のない仮のタイル、エラー＝「読み込めませんでした」と［再試行］で代用している。新しい状態の文字は足さない。
  • 読み込み中やエラーのときは、そのタブの位置の保持を上書きしない（読み込みが終わったら、保持していた位置へ戻す）。

7. フォントの違い（Androidとブラウザ）

  • Androidの sans-serif-medium は、英数字が Roboto Medium、日本語は端末の日本語フォント（多くは Noto Sans CJK JP の Medium）になる。
  • このHTMLは Roboto と Noto Sans JP を指定しているが、入っていない環境ではブラウザの標準フォントで表示される。文字の幅や行の高さは、実機と数%ずれることがある。
  • 日本語は1文字がほぼ1em幅なので、「すべての写真」（6文字）は16sp×1.3倍＝20.8spで約125dp。320dpの幅でタブ1つは約152dpなので収まる。#11の枠（48dp）が入ると約128dpになり、余裕は数dp。実機での確認が必要（8. 参照）。
