4. ブラウザとAndroidのフォントの違い

  • Androidの sans-serif-medium は、英数字が Roboto Medium、日本語は端末の日本語フォント（多くは Noto Sans CJK JP の Medium）。このHTMLは Roboto と Noto Sans JP を指定しているが、入っていない環境ではブラウザの標準フォントになり、文字の幅や行の高さが実機と数%ずれることがある。
  • 「タグ」「その他」は2〜3文字なので、320dp・1.3倍（約17sp）でも1行に収まる余裕は大きい。
  • HTMLの外枠は outline で描いていて、内容の幅（320dp／400dp）は狭めていない。
