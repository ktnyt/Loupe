3. 取り消しの動き（既存のまま）

  • 押すと、直前の1操作だけを取り消す。
  • 取り消せる操作がないときは無効（#626B72）。読み上げも「無効」になる。
  • 取り消しの保存に失敗したときは、今の状態をそのまま保つ（取り消す前の状態に戻さない・進めない）。このHTMLでは記録にだけ出し、画面に新しい文は足さない。
  • 読み上げ名：「直前の操作を取り消す」。ツールチップ（長押し・ホバー）も同じ文。

4. 確認の観点

  • 縦320・400dp、横640・800dp、文字1.0・1.3倍のすべてで、各ラベルが1行・欠けなし・操作の領域48dp以上。
  • 比較の dock は、比較中の1位方式（3操作）・比較中のすべての順位方式（4操作）・比較終了（3操作）・共有から来たとき（選択へ戻る）のすべてを検査。
  • 連写の詳細の4操作の dock と［1位にする］［共有］も、同じ条件で検査。
  • 主操作の3つの状態（ソート／ソートを再開／ソート結果）すべてを、全幅の条件で検査。
  • 比較のため、Aの左に「直前の操作を取り消す」、Bの左に元の名前（順位を決める・この写真を1位に）と固定4列を置いている。
  • ［選択］［その他］の行は参考として同じ検査をしているが、変更しない（結果に「参考」と付く）。

5. フォントの注記

  • Androidの sans-serif-medium は、英数字が Roboto Medium、日本語は Noto Sans CJK JP Medium（多くの端末）。このHTMLは Roboto と Noto Sans JP を指定しているが、ない環境ではブラウザの標準フォントになり、幅が数%ずれる。
  • 日本語は1文字がほぼ1em。「取り消し」（4文字）は13sp×1.3倍で約68dpで、320dpの均等3列の中身（約89dp）に入る。「直前の操作を取り消す」（10文字）は約169dpで、400dp・1.0倍でも中身（約116dp）に入らず2行になる。
  • 行の箱の24dpは、Androidの includeFontPadding の高さを模したもの。実機では13sp・1.3倍でもボタンの高さ64dpを確認済み。
  • アイコンのSVGは既存の参照のまま（このファイルでは新しいアイコンを追加していない）。本体の線形に合わせる正規化は別途。
