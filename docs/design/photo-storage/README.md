# 写真保存先と移動の検証画面（#162）

2026年11月22日（日本時間）のAndroid画面記録。現行の操作契約は[写真保存先の契約](../../photo-storage-contract.md)、視覚設計は[Material 3 UI契約](../../material3-ui.md)を参照する。これらの画像は検証記録であり、新しい画面の視覚的な基準ではない。

| 記録 | 条件と観測 |
| --- | --- |
| `physical-native-*` | 実機Android 16、1200×2670px、520dpi、縦画面。指定400dpを実表示幅369dpに制限、font1.0。USB SDへの保存先選択と確認。 |
| `physical-compact-*` | 同じ実機、320dp/font1.3。設定・単一選択・移動不可1枚を含む確認、キャンセル後の原本保持。 |
| `emulator-completed*` | Android 15、400dp/font1.0。画面から移動を確定しforeground serviceが完了。完了1・未処理0・移動不可0または1、移動先の全バイト・履歴・元ファイル不在を照合。最終結果文はエミュレータで確認。 |
| `emulator-progress` | 同じエミュレータの移動中。進捗、中止、競合する操作の無効状態。 |
| `emulator-confirm-skipped` | 対象1枚と移動できない1枚、その説明を表示。対象外の履歴は処理後も保持。 |

別applicationIdの検査用アプリと合成JPEGだけを使用した。表示幅とfontは検査プロセス内で変更し、端末の設定は変更していない。画像はOS領域を含むAndroidスクリーンショットで、描画が安定したフレームを取得した。

実機ではUSB SDへの全バイト移動、取り込み履歴・タグ・順位・共有履歴、各中断境界からの復旧を検証した。Androidの安全な取り外しと再接続では、未接続中の履歴保持、元カード不在で移動を終了した後の識別分離を確認し、カードを接続状態へ戻した。物理的な抜線や既存写真の一括移動は実施していない。

画像とAX操作記録を独立したレビュー担当が評価した。最終結果文と進捗はエミュレータでの観測であり、実機での最終文言の確認、進捗画面からの中止・再開、障害回復画面、TalkBack音声、keyboard/focus順は未検査。backendの取消・再開テストと、画面操作の検証は区別する。実カメラMTP/Wi-Fi転送と実AI/e2通信はこの検証に含まない。

詳細と試行記録: [Issue #162](https://github.com/ktnyt/Loupe/issues/162)
