Loupe Issue #10 — 比較写真にA/Bを重ねる

比較部品だけの模擬です。写真はダミーの色面で、下のボタンは既存ボタンの簡略模擬です。写真をタップすると選択、長押し（0.5秒）で拡大します。

A/B と操作の対応ログ

1. 変更範囲

対象現行#10
位置の説明文「Aは上の写真 · Bは下の写真」「Aは左の写真 · Bは右の写真」削除
案内文「比較中の好きな写真を選んでください」削除
A/Bラベル—各写真の実画像の左上の隅に重ねる（新規・装飾）
変えないもの順位のロジック、FIT_CENTERでの写真全体の表示、面積で上下／左右を選ぶ判定、A＝ranking.upper（上または左）・B＝lower（下または右）、タップ＝選択・長押し＝拡大、下部の［Aを選ぶ］［Bを選ぶ］［Aを拡大］［Bを拡大］、取り消し・同率・中断と再開・拡大・保存、読み込み前と失敗時は選べない契約。結果画面の案内（#14）、モード（#6）、全体の配置（#8・#9）

2. ラベルの数値（Android実装用）

項目値
置く場所各写真の実画像の領域（FIT_CENTERで描かれた範囲。ImageView.imageMatrix と画像の寸法から求める矩形）の左上の隅。スロットの余白には置かない。A・Bとも同じ左上
画像の端からの余白上・左とも8dp。実画像の短い辺が96dp未満のときは4dp
大きさ最小 24×24dp。左右の内側の余白7dp、上下2dp。文字が大きいときは中身に合わせて広がる（1.3倍で約26×25dp）
形角丸6dp の四角
背景#0F0F10 を不透明度72%（#B80F0F10）。外側に1dpの線 #EDEDEA を不透明度45%（#73EDEDEA）
文字「A」「B」の1文字。13sp、sans-serif-medium、#EDEDEA、行の高さ16sp、左右中央
見分けやすさ明るい写真の上では暗い背景が、暗い写真の上では明るい線と文字が、細かい模様の上では無地の背景が輪郭をつくる。文字とラベル背景のコントラストは、真っ白な写真の上で約6.6:1、真っ黒な写真の上で約16.7:1（どちらも4.5:1以上）
中央を邪魔しないラベルは隅だけ。実画像の短い辺が96dp以上なら、ラベルが画像に占める幅は最大で約3割以下（320dpの左右配置の縦長でも、中央の半分には入らない）
はみ出さないラベルは常に実画像の矩形の中に収める：x = 画像左 + 余白、y = 画像上 + 余白。画像がラベルより小さい極端な場合は、余白を0dpまで減らしてから、それでも入らなければ表示しない（読み上げ名には常にA/Bが入る）
操作装飾。クリック・長押しを受けない（clickable = false、importantForAccessibility = no、または画像のViewの上に描画するだけ）。写真のタップ・長押しをそのまま通す
選択中の見た目既存のまま（このHTMLの白い内側の線は模擬）。ラベルは選択で変えない

3. 読み上げ名（画像の contentDescription）

状態読み上げ名
表示済み「A、{写真名}、タップで選ぶ、長押しで拡大」／「B、{写真名}、タップで選ぶ、長押しで拡大」
読み込み中「A、{写真名}、読み込み中」（選べない）
失敗「A、{写真名}、読み込めませんでした」（選べない）
ラベル読み上げない（画像の読み上げ名に含まれるため）

「上の写真」などの位置の言葉は、読み上げにも入れない（位置は画面ごとに変わるため）。

4. 読み込み中・失敗・再表示

  • 読み込み中と失敗のときは、実画像の範囲がまだ決まらないので、既存の仮の表示（スロット全体）の左上に、同じ余白・同じ見た目でラベルを置く。選べない契約は既存のまま。
  • 読み込みが終わったら、ラベルを実画像の左上に置き直す（移動のアニメーションはしない）。
  • 再表示（画面の再生成や回転のあと）も、実画像の矩形を求め直してから置く。前の位置を使い回さない。

5. フォントと確認の注記

  • Androidの sans-serif-medium は英字が Roboto Medium。このHTMLは Roboto を指定しているが、入っていない環境ではブラウザの標準フォントになり、ラベルの幅が1〜2dpずれることがある。
  • 比較部品の大きさは例として幅320／400dp × 高さ420dp。上下と左右の切り替えは、2枚の実画像の面積の合計が大きい方を選ぶ既存の判定を模擬している（スロットの間隔は現行Androidに合わせ0dp）。
  • 下の［Aを選ぶ］などのボタンは既存ボタンの簡略模擬で、寸法・配置は再設計していない。
