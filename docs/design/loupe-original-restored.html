Loupe UI ブラッシュアップ — 元のデザインの復元（全51画面）

元のデザインアーティファクト「Loupe UI ブラッシュアップ」の各ボードを、元の実行環境で描いた結果をそのまま静的なHTMLに書き出したものです。見た目・文言・情報構造は元のまま変えていません（再デザインなし）。support.js・DCLogic・外部のスクリプトやCDNには依存しないので、ローカルで開いても白紙になりません。各画面は 1px＝1dp の実寸で並べています。

データは元のデザインにある合成の例だけです（実際の写真・利用者のタグ・秘密情報は含みません）。これは見た目の照合用の静止画で、ボタンを押しても画面は移りません（内側のスクロールは動きます）。操作できるプロトタイプは「00」の初期画面だけを収めています。フォントは元と同じく Noto Sans JP を指定しています。外部から読み込まないので、端末に Noto Sans JP がない場合は system-ui で表示され、文字の幅が数%ずれることがあります。
