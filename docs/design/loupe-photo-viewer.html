2. 元からの違い（合意した必要な変更だけ）

#場所元のデザイン変更後理由
1dock の［戻る］左端に［戻る］外す。端末のBackで開いた元の画面・位置へ戻る#5
2dock の［拡大］—（比較中の拡大 S06 は大きな［等倍表示］ボタン）［戻る］が空けた枠に小さな［拡大］（押すと2倍になり名前が［全体］に変わる。読み上げは「拡大」と押されていない状態／「全体を表示」と押された状態・aria-pressed）。ピンチとダブルタップの拡大はそのまま。読み上げでも届く拡大の操作として残す。S06の大きなボタンは置かない既存の拡大
3読み込み—取得の仕組みは既存のまま：プレビューを先に出し、そのあと既存の OriginalCache が原本を自動で取得する（クラウドだけの写真も同じ）。新しいダウンロードの仕組みや進み具合は足さない。表示は#17の印だけ（文は出さない）。読み込み中：写真の場所の右上に回る弧（400msまでは出さない）。プレビュー表示中で原本を取得中：格子の印＋回る弧の札（高さ28dp・数値なし）。原本の失敗でプレビューが残る：格子＋三角の札（押すと再試行・48dp）。すべて失敗：写真の場所に #19191B の地と三角の印、［再試行］（48dp）#17
4撮影日時常に日時分かっている撮影日時、なければ更新日時（見た目は同じ形、読み上げで「更新日時」と言う）。今年なら「月日 時刻」（例「10月18日 13:34」）、別の年なら年を付ける（例「2025年12月31日 23:59」）。どちらもなければ「—」（読み上げ「日時は分かりません」）。日時を作らない既存の情報
5［タグ］いつも出す比較・結果から開いたのではない content:// の写真だけ出す（ほかは dock から外して列を詰める）。押すと既存の「この写真のタグ」（T16）既存の条件
6［情報］—（中身なし）元の「その他」と同じ形のシートで、ファイル名・機種・大きさ・フォルダ（長い値は折り返す）。Backで閉じる既存の情報
7比較・結果から開いたときS06（比較中の拡大：［等倍表示］［こちらを選ぶ］［比較に戻る］）同じ黒い S08 の形の Main の写真の画面。写真は開いた1枚に固定（スワイプでほかへ移らない・前へ／次へは出さない）。dock は既存の［拡大］［共有］［情報］（［タグ］は出さない）。未完了の比較だけ dock の上に既存の白い［この写真を選ぶ］（52dp・角丸26dp・S06の形）を置き、写真の舞台の下は160dpにする。完了した結果では出さない。Backで比較・結果へ戻り、順位・スクロール・フォーカスはそのまま既存の動き#5
8タグの画面（TagActivity）から開いたとき—（V09の1枚ずつ確認とは別の画面）同じ黒い写真中心の形。dock は［前へ］［次へ］［拡大］と既存のタグの操作（タグ付きなら［タグを外す］、該当しないなら［タグを付ける］）。保存中は既存の busy のガードどおり、その操作は回る弧で無効、前へ・次へも無効、Backも保存が終わるまで戻らない。保存の失敗は判断を変えず、操作の右上に失敗の印、もう一度押すと再試行。共有はない既存の動き
9最初・最後無効の色そのまま（#626B72・読み上げは「無効」）。前へ・次へは端末・クラウドのどのファイルでも出す元のデザイン
10固定タブ—写真の画面は子画面なので出さない#12

3. 既存の Android の契約で確定したこと

#点確定
1拡大の操作dock の小さな［拡大］／［全体］を見える形で残す。読み上げの押された状態（aria-pressed）を正しく出す
2比較・結果から開いたときの操作既存の Main の写真の画面なので［共有］［情報］がある。dock は［拡大］［共有］［情報］。［タグ］は比較・結果ではない content:// の写真だけ。未完了の比較の操作は既存の名前「この写真を選ぶ」
3タグの画面の操作の名前「タグを付ける」「タグを外す」
4タグの保存中既存の busy のガードで前へ・次へ・Back を止める。失敗は今の判断を保ち、もう一度押すと再試行
5［共有］既存のメニューを開く（中身はここで繰り返さない）
6日時今年は月日と時刻、別の年は年を付ける。撮影日時がなければ更新日時（読み上げ「更新日時」）、どちらもなければ「—」
7原本の取得既存の Main の写真の画面は、プレビューを出したあと OriginalCache で原本を自動で取得する（クラウドだけの写真も）。この動きを保つ（プレビューだけにしない）。新しいダウンロードの仕組み・進み具合の表示は足さない
  • 減らす動き：前へ・次へでの写真の移り変わりと拡大は動きなしで切り替え、回る弧も止める。
  • 読み上げ：写真は「写真、{日時}」（クラウドなら「、クラウドにあります」、拡大中は「、拡大中」）。拡大の操作は読み上げのジェスチャーでも届く。
  • フォントは Noto Sans JP を指定（ない環境では system-ui）。外枠は outline。
