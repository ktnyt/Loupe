2. 変えないもの

  • 比較のモード選択「1位を決める」「すべての順位を決める」（順位を表す説明のため維持。伝え方は#6で別途設計）。
  • 順位の値、1位方式（選んだ写真が1位、残りは同率2位）、すべての順位を決める方式、保存形式。
  • 「順位が未決定」「順位決定済み」などの状態表示と、フィルター「1位」「順位が未決定の連写」。#17で文字から見た目へ変える予定のため、「ソート済み」などへの置き換えはしない（版29の文言のまま）。
  • 「直前の操作を取り消す」「あとで続ける」など、ソートの名前を含まないほかの操作名。
  • 色・形・寸法・アイコン。全体の配置、文字欠け、戻る、A/B表示は別issue。

4. 読み上げ

  • ボタンの読み上げ名は、見えている名前と同じにする（「ソート」「ソートを再開」「ソート結果」「再ソート」）。アイコンは読み上げない。
  • 見出しは見出しとして読み上げる（「ソート」「ソート結果」）。
  • 確認ダイアログは見出し → 本文 → 実行 → 戻るの順。文言は表と同じ。
  • 状態（順位が未決定など）の読み上げは今回変えない（#17で扱う）。

5. 確認の観点（文字1.3倍・狭い幅）

  • 412・360・320・280dpの幅と、文字1.0倍・1.3倍のすべての組み合わせで、対象の名前が省略されずに読めること（折り返しは可、「…」での省略や切れは不可）。
  • 対象のボタン・メニュー項目のタップ領域が、高さ・幅とも48dp以上であること。
  • 上の比較部品の下に、表示中の組み合わせの判定を出している。
