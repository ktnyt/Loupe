# Loupe UIデザイン案

[2026-10-25版の画面一覧・操作プロトタイプ](loupe-ui-2026-10-25.html)

HTMLをダウンロードし、ブラウザで開いてください。GitHub上ではソースが表示されます。Reactとフォントの外部CDN参照が含まれるため、インターネット接続のある環境を推奨します。

Claude Designから書き出した18画面分のデザイン資料です。適用要件・未決定事項は [Issue #2](https://github.com/ktnyt/Loupe/issues/2) を参照してください。

この版は修正前の問題も含む参照案です。選択時のチェック表示によるチップ幅・隣接ボタン位置の変化は、実装時に解消します。単写真の★機能の扱いなど、Issueの未決定事項をこの資料だけで確定させないでください。プロトタイプの挙動はAndroid実機での動作保証ではありません。
