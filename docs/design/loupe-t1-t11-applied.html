2. T11 クラウドと同期の差分

場所元のデザイン変更後理由
下部［戻る］だけの dockdock ごと外す#5
「同期」のカード説明の文＋［同期を予約する］（予約後は無効の「同期を予約しました」）見出しの行の右に、バックグラウンド同期（progress）の印と時刻、自動同期の保存済みの値のスイッチ。本文の下に観測の2行「写真情報の読み取り」（collection の印）と「写真の集計」（数または「—」）。ボタンは［同期を予約する］（予約後は無効・完了の印を添え、文字は操作名のまま）と、既存の［状態を更新］。補足の領域に原本の保存・モバイル通信・原本の位置情報の説明と、未許可のときだけ［位置情報の読み取りを許可］#17・#8の既存の条件（観測値は別々に出す）
「保存した写真の確認」のカード説明＋結果の文「確認した写真はすべて元どおりダウンロードできました」＋［確認する］結果の文を印（完了＝塗りのチェック、未確認＝点線の丸、確認中＝回る弧）にし、文は読み上げへ。［確認する］はそのまま（確認中は無効・回る弧）#17
「端末の写真を自動で削除」のカード見出し＋スイッチ（オンで確認21）、要約の2文、「端末に残す期間 ［基準日］から30日」＋［変更］スイッチと要約の2文はそのまま。観測の行「自動管理の権限」（permissionState の印）。期間は「撮影日から30日」（7／30／90日）。［変更］で選ぶと、同じ日数でも端末からの自動削除はオフになる（cleanupEnabled=false）。補足の領域に削除の条件・日付の条件・アプリを削除したときの現行の全文と、isExternalStorageManager が false のときだけ［写真の自動削除に必要なアクセスを許可］#8の既存の条件・#17
見出し上の大きな領域（高さ424dp）・「クラウドと同期」28dp・「最後の同期：10月18日 14:05」は元のまま元のデザイン
  • 観測値（collection・info・permissionState・progress）はそれぞれ別の値で、ほかの値から推測して変えない（権限がないことから同期を一時停止などにしない）。
  • 読み取りの更新中も、どの操作も無効にしない（［同期を予約する］の予約済み・［確認する］の確認中は、元のデザインの無効のまま）。
  • 5枚の別カードや、下部の設定の入口（［同期・端末からの削除］［その他］）には戻さない。設定の変更はカードの中のスイッチと［変更］から直接行い、オンにするときは元の確認（21）を出す。
  • 確認21の本文の「［基準日］から30日」は「撮影日から30日」（選んだ期間）にした。21の画面のほかの見直しは次の作業で扱う。

4. 確認の観点・注記

  • 320／390／400dp・文字1.0／1.3倍で、省略・切れ・文字の縮小・はみ出し・下部と内容の重なりがないこと、押せる部品が48dp以上であることを右の検査で確かめる。
  • Back：シート → 画面 → 呼び出し元 → OS。アプリの中に戻るボタンは置かない。
  • 減らす動き：回る弧を止める（形はそのまま）。
  • フォントは Noto Sans JP を指定。入っていない環境では system-ui になり、文字の幅が数%ずれることがある。外枠は outline で、寸法の外側にある。
