Loupe — 現像（実験）：CNT-like ルック研究 PoC の最小UI（Issue #67：周辺光量・測定LUTの枠）

左は元のアートボード S08「08 写真詳細」、右は loupe-tone-curve-final.html と同じ画面です。上の行の「現像▾」（48dp）から、下に重なるスクロールのシートで、既存の現像のあとにかける追加のルック（Neutral／CNT-like（仮）／Custom、トーン、LUT、粒子）を比べて調整します。CNT-like（仮）は組込みの測定LUT（このHTMLには未同梱・プレビューは無変換）と周辺光量100を使い、トーンは直線、粒子はオフです。LUT と粒子のあいだに独立した周辺光量（オン／オフ・強度）を足しました。ルックのカーブはトーンタブのパネルで［現像｜ルック］を切り替えて編集します。7つのタブ・写真の viewport・比較・保存・原寸の準備と失敗からの復帰は前のままです。

Leica CNT の再現ではありません。仮説の CNT-like を比べるための研究用の PoC です。この画面の色・LUT・粒子は近似で、実機での画質の検証とは別です。写真は合成の色面と図形だけです。測定LUTはこのHTMLに同梱していません。Androidにはまだ反映していません（Issue #67）。

3. プリセットの決まり

操作動き
Neutral確認してから：追加のルック（周辺光量を含む）をオフにし、現像の補正（7つのタブの値・トーンカーブ）も中立、ロールオフ 0 にする。元に戻せない。読み込んだ LUT と Custom の値は残す
CNT-like（仮）追加のルックだけを置き換える（現像の補正は変えない）。
トーン オン・5本とも直線（identity）。
LUT オン：組込みの測定LUT（このHTMLには未同梱・プレビューは無変換）・強度100（読み込んだ LUT は使わずに保持）。

Customプリセットのあとにルックを変えると自動で Custom（元にしたプリセットを覚える）。ほかのプリセットへ移っても Custom の値（どの LUT を使うかを含む）を保持し、Custom を押すと保存しておいた手動の値へ戻る
リセット元にしたプリセットの値へ追加のルックだけを戻す（Custom の値は保持）

4. LUT（組込みと .cube の読込）

項目契約
LUT の持ち方組込みの測定LUT（CNT-like（仮）が使う・このHTMLには未同梱でプレビューは無変換）と、読み込んだ LUT（1つ）を別に持つ。読み込むと読み込んだ LUT を使い（Custom）、CNT-like（仮）に戻すと組込みを使う（読み込んだ LUT は保持）。状態の行に「使用中：…」と「読み込み済み：…（保持）」
.cube の条件3D のみ（LUT_3D_SIZE 2〜65）。値の数は N³。ファイル 32MiB まで（65³ は約27万行で 8MB を超えるため）、1行 4096 文字まで。値は sRGB で符号化した値用（入力・出力とも 0〜1、DOMAIN_MIN／MAX で正規化）
読み込み中回る印＋「読み込み中…」。［.cube を読み込む］とスイッチは無効
成功読み込んだ LUT をオンにして使う（Custom になる）
無効形式の誤り（LUT_3D_SIZE なし・1D・2〜65 の外・値の数が N³ でない・数でない値・1行が4096文字を超える）。理由を表示し、前の LUT をそのまま保持。［再読込］
失敗読み込めない・32MiB を超える。前の LUT を保持。［再読込］でファイルを選び直す
中断・再開読み込み中にバックグラウンドへ移ると中断（前の LUT のまま・［再読込］）。戻ったときは「再開：前回のルックを復元しました（LUT はアプリ内の複製から）」

4b. 周辺光量（#67）

項目契約
位置シートの LUT（強度のスライダー）と粒子のあいだ。1dpの区切り線のあとに［周辺光量 ●］のスイッチ（高さ48dp）と「強度」0〜100 のスライダー（つまみの操作域48dp・右に数値）。ほかの部品と同じく縮まない
値CNT-like（仮）：オン・100。Neutral：オフ。強度の既定は100（ダブルタップ・Delete で100へ）
保持LUT・粒子とは独立。.cube を読み込んでも変わらない。Custom の値に含めて保持・復帰。カーブの元に戻す／やり直すでは変わらない。未保存の破棄・再開では保存時の値に戻る。リセットは元のプリセットの値（CNT-like ならオン・100）
処理の順現像 → ルックのトーン → LUT → 周辺光量 → 粒子。このHTMLのプレビューは近似（画像に重ねた放射状の暗さ。強度100で隅が約50%暗く、写真といっしょに拡大・移動する）。比較のときは外す

5. トーンタブ：現像／ルックの切り替え（パネルの高さ264dpのまま）

  • 3行目（48dp）を ［現像｜ルック］（2つの角丸ボタン・各 高さ48dp・幅48dp以上・13sp）＋ 右の部品 に変えた。現像のときは右に既存のロールオフ（スライダー）、ルックのときは右に［トーン ●］のスイッチ（ルックにはロールオフなし）。
  • 1・2行目（カーブの選択・グラフ・入力／出力・元に戻す・やり直す・削除）は同じ部品で、ルックのカーブ（5本・Oklab L → RGB → R/G/B・32点・最小間隔1/128・PCHIP）を編集する。ルックのトーンがオフのときは、線を点線・40%で描く。ルックのカーブを変えると Custom になる。
  • 適用の順：現像（ロールオフ → 明度 → RGB → R/G/B → ほかのタブ）→ ルックのトーン → LUT（強度で混ぜる）→ 粒子。

6. 比較・保存・未保存

  • ［比較］は既存の1回のタップ（補正前、ルックも外す）。左右の分割は省略。
