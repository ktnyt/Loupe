#点決定
1#7 の名称適用：「順位の結果」→「ソート結果」、「付け直す」→「再ソート」。名前だけの変更で、動き・確認・順位のロジックは変えない

3すべての写真の「ほかのアルバム」の横送り元のまま保持

5結果の写真を押したとき既存の写真詳細（S08）の拡大へ進む。順位と共有の状態は保持し、Backで結果へ戻る
6V06の副題「該当しない」写真の判断のデータなので文字のまま保持
7フィルターの幅への対応入らないときだけ折り返す案を採用
—ファイル名の出どころ原本のファイル名を表示用に読む（原本は読み込まない・変更しない）。このHTMLは合成の名前
—固定タブと下部の積み重ねタブを最下部、その上に元の下部をそのまま積む（#12の配置）
  • 原本の保存・送信・削除、順位、タグの判断の条件は変えていません。追加した読み取りは表示用（ファイル名・プレビュー）だけです。
  • Back：シート → 画面 → 呼び出し元 → OS。ルート（アルバム・すべての写真）ではアプリを離れ、別のタブへは戻しません。アプリの中に戻るボタンは置きません。
  • 文字1.3倍では、元の固定の高さ（64dpのボタン・36dpの札・48dpのボタン）を最低の高さとして扱い、伸びても切れないようにしています（1.0倍の寸法は元と同じ）。
  • フォントは Noto Sans JP を指定。入っていない環境では system-ui になり、文字の幅が数%ずれることがあります。外枠は outline で、寸法の外側にあります。
