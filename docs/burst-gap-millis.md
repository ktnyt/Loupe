# 連写候補の撮影間隔

## 目的と機能

同じ機種・保存先・形式の写真をまとめる撮影間隔を、既存の選択肢と任意のミリ秒入力から選べるようにする。写真原本の撮影日時・内容は変更しない。撮影時刻にミリ秒精度がなければ、入力によって元データの精度が増すことはない。

## 要件と契約

- 既存の「まとめない」「1秒以内（標準）」「2秒以内」「3秒以内」を保持し、「カスタム（ミリ秒）」を追加する。
- カスタムは1〜2147483647の10進整数ミリ秒を受け付ける。0は既存の「まとめない」で指定する。上限は保存するintの範囲であり、秒への丸めや単位変換によるオーバーフローを起こさない。
- 空欄・符号・小数・数字以外・範囲外は入力欄でエラー表示し、保存せずダイアログを保持する。前後の空白は除去して検査する。
- 既存のburstGapSecondsが0〜3なら、それぞれ0/1000/2000/3000ミリ秒として読み取る。新しいミリ秒値を保存済みならそれを優先し、未設定の初期値は1000ミリ秒とする。
- カスタム画面を開くと現在のミリ秒値を表示する。「保存」でのみ設定を確定し、キャンセル・Back・外側タップでは設定や索引を変えない。保存失敗はエラーを示し、閉じずに再試行できるようにする。
- 正常保存後は連写詳細から戻り、索引を再構築する。索引signatureと実際のグループ分けは同じミリ秒設定を使う。
- BurstGroupsは隣り合う撮影時刻の差が閾値以下ならまとめ、閾値を超えれば分ける。無効化、機種・保存先・形式・動画・撮影時刻不明の既存条件は保つ。
- 連写の順位・タグ・共有履歴を変更せず、既存グループ再構築時の扱いに従う。

依頼された任意入力と既存動作の維持を要件とし、入力上限・確定時点・移行方式は委譲範囲で具体化した契約とする。独立したリファクタリングは不要。

## UI契約

対象は写真一覧の設定→「連写のまとめ方」と、そのカスタム入力画面。既存の選択肢は即時確定を保持し、カスタム選択時だけMaterial 3の入力ダイアログを開く。カスタム値を選択状態と現在値で判別でき、1000/2000/3000は対応する既存選択肢で示せる。入力欄は「撮影間隔（ミリ秒）」として読み上げ可能にし、整数用キーボードを使う。入力エラーを色だけに依存させない。

Material 3標準部品、48dp以上の操作領域、スクロール可能な内容、OS領域とIMEを避ける配置を使う。通常幅/font1.0と320dp/font1.3で入力・エラー・保存・キャンセルを確認する。エミュレータでの画面/操作確認と物理端末の確認を分けて記録する。

## 検証と対応

実装前契約。単体検証でミリ秒境界・入力検証・旧秒設定の互換性、Android検証で保存・再表示・キャンセル・入力エラー・設定の復元を確認する。索引の使用単位も確認する。保存完了が確定の終点、索引公開は既存のindex.publishedを終点とし、計測できない実データでの再構築時間は未計測と記録する。実装と検証結果はissue #188に記録する。
