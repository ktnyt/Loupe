# 連写内で選んだ写真の一括1位指定

対象: Issue #84。連写内で残したい写真を複数選び、一度の操作で同率1位へ追加する。

## 機能と契約

- 連写詳細の「選択」で既存の個別選択グリッドを開く。当該連写でチェックした写真だけを指定対象にする。共有の1位限定設定は順位変更の対象に影響しない。絞り込みで隠れている選択も含め、他の連写の選択は含めない。
- 確定済みなら現在の1位を残して選択写真を1位へ追加し、残る下位グループの順と同順位を保持する。競技順位を再計算する。全対象が既に1位なら保存しない。
- 未着手・比較途中なら確認を経て、選択写真を同率1位、残りを同率次位として確定する。確認画面は途中の比較を置き換えることを伝える。
- 0枚では実行不可。1枚・全枚選択にも対応する。確認時の対象集合と元の順位を固定し、一つの互換journalを一度保存する。写真ごとの部分保存はしない。
- 取消・Back・外側タップは無変更。保存中は重複実行と閉じる操作を抑止する。失敗時は元の順位へ戻し、同じ対象で再試行できる。
- 成功時だけキャッシュと表示を更新する。同じ連写の選択画面に留まり、選択集合とスクロール位置を保持する。表示上の順位と1位限定共有は同じ確定結果を参照する。
- 写真原本、タグ、別連写の順位、共有の設定を変更しない。既存の保存キーと履歴形式を維持する。

## 選択画面

- 連写の枚数を見出しに表示する。1位は星、下位は白文字の順位と半透明の黒いピルで写真上に示す。
- 320dpと通常369dpの縦画面では文字1.0/1.3倍で、既存の4つの順位フィルタが折り返しても「選択を終了」「すべて選択」のアイコンとラベルを表示する。短い画面では下部パネルをスクロールできる。

## 検証と計測

モデルでは複数昇格、既存1位・下位グループ保持、未確定、重複・未知ID、無変更を確認する。保存境界では単一保存、失敗復帰と再試行、再読込を検査する。

合成写真を使う実機操作で選択グリッドから複数選択し、取消・保存・失敗・再試行・選択保持・共有設定との独立を検査する。320dpと通常369dp、文字1.0/1.3倍の縦画面で参照HTMLと比較する。入力から結果フレームまでを計測し、写真の識別子や原本はログへ出さない。実指、実際のTalkBack音声、外部共有先での動作を別途区別する。

文字拡大時の下部操作は、固定比率で切らず見出しと96dp写真1行を残す範囲に収める。短い画面ではスクロールで全操作へ到達できる。保存失敗は警告の印、保存成功は丸いチェックの印を付ける。
