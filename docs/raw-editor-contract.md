# 実験的な内蔵RAW現像

対象: Issue #53。実装前の契約。Lightroomとの画質・数値互換は保証しない。

## 目的・要件・状態

Android端末内でRAWを現像し、主題を拡大して質感を決め、全体の明暗・色を整える流れと2DUIを評価する。5タブと3サブタブはissueに記載した利用者指定。長辺2048px以下の初期実験、WBは撮影時基準からの相対調整、明度は中間調中心の調整、色別調整は後続候補、という具体化は今回の実験範囲。

## 原本・入出力

- 原本は読み取り専用。ローカルURIからアプリ専用の一時コピーを作りRAWデコーダーへ渡す。原本・URI・パス・写真内容をログや外部サービスへ送信しない。
- LibRawで実RAWの画素を展開する。埋め込みJPEGを現像結果と呼ばず、RAW読込失敗をJPEGへの代替で隠さない。JPEG入力はJPEGとして区別。
- `NativeRaw.decode(path,maxSide)` は読み取り可能なファイルを受け、縦横正数・長辺maxSide以下・RGBA各32bit float・行優先のlinear sRGB画像を返す。alpha=1。カメラWBを基準とし、色温度/色かぶりはその基準への相対補正。maxSideは256..2048へ制限、入力寸法/画素数/ファイルサイズを検証する。失敗時は例外、途中結果を返さない。バッファはJava所有のdirect ByteBuffer、共有のnativeポインタを持たない。
- 初期実験はLibRawのhalf-size現像と長辺2048px以下の縮小を許容。デモザイク/色変換段階で失ったハイライトは回復保証しない。商用品質・Adobe Color初期発色と同一ではない。
- 出力は同一の調整済み画素からsRGB JPEG、長辺2048px以下。保存前に寸法と「実験」の表示。MediaStoreの新規pending出力へ書き、書込と公開成功後のみ完了。失敗/中止は今回の不完全出力を削除し、原本や既存出力を変更しない。EXIF個人情報は継承しない。

## パラメーターと操作

- WB: 相対温度/色かぶり。質感: テクスチャ/明瞭度、かすみの除去。トーン: 端点固定、制御点1つ。ライト: 露光EV/中間調明度、ハイライト/シャドウ＋コントラスト、白/黒。カラー: 彩度/バイブランス。
- 面・右辺・下辺は同一状態を更新。面は両軸、右辺は縦軸のみ、下辺は横軸のみ。中立値/範囲/有限値をモデルが保証。タブ切替では値を保持。現在タブの初期化だけを行える。
- 彩度MAXは表示専用。WB以外への移動・背景化・保存時は解除。ユーザーの彩度値や保存結果を変えない。補正前表示も表示専用。
- 画面の操作順と画素の計算順は別。全パラメーターを状態として保存し、同じ状態なら操作順によらず同じ結果。
- 写真はピンチ・パン・全体表示が可能。変更を戻す際も拡大位置を保つ。未保存の変更はBackで破棄確認。ロード/保存中の離脱はキャンセルし、後から画面を更新しない。

## 非同期・性能

- 読込と保存はUIスレッド外。調整処理はGLスレッドで最新状態だけ描画、古い要求を溜めない。停止/破棄時は所有リソースを解放。ライフサイクルで再読込/状態復元を行う。
- 調整開始→画面への反映、RAW読込、保存開始→公開完了をmsで計測。寸法・形式・成功/失敗のみログへ記録し、写真の識別子を含めない。
- UI参照HTML完成まではAndroidのUI実装へ進まない。native読込・モデル・処理基盤は独立して準備できる。

## 検証計画と未確認

単体: 範囲・中立・片軸不変・彩度MAX出力除外。合成実機: 全タブ/スライダー/面/カーブ/比較/保存/再読/失敗/中止。実RAW: GR DNGとOM ORFを読み出し、表示・拡大・調整・JPEG別保存・原本hash不変。初期実験では端末内で行い写真はリポジトリへ追加しない。Claude参照との独立UI評価、Cold Review、Security Review。現時点ですべて未検証。

## 実装前のUI具体化

Claudeが完成した `design/loupe-raw-editor.html` を基準とする。原S08を直接表示し比較した。上56dp、下タブ64dp＋下余白20dp、調整欄のみスクロール。面Sは `max(120,min(幅-88,(高さ-140)*.36))` dp、辺48dp・間隔8dp。色 #0F0F10/#141416/#EDEDEA、文字13sp/12sp。露光±5EV、カーブ入力5..95%、出力0..100%。この数値範囲は上記モデル具体化に優先。Backは読込を取消、未保存時破棄確認、保存中は不可。比較/MAXは保存対象外、初期化はタブ単位（ライトは3サブタブ全体）。独立APKは `jp.nano.rawgallery.rawexperiment` として既存0.18.12/138を上書きせず併設する。主アプリには同一エディターを内蔵するが、今回端末へインストールするのは独立APK。
