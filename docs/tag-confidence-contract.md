# 判断から学習するタグConfidence

## 目的と合意

少ない判断で、背景や撮影日が異なる写真にも本人のタグ基準を反映し、表示範囲を調整できる。Issue #46は、判断から学習する判定器・連続スコアの保存・閾値閲覧・追加判断の操作を実装する。

優先例はミカヅキインコ、オカメインコ、キキョウインコ。写っていれば対象で、同じ写真に複数タグを許す。各タグは独立し、一つのタグの付与を他タグの負例にしない。種を識別する精度、BioCLIPとの比較、部分画像、確率校正は親issue #1の評価範囲であり、合成テストで保証しない。

## 機能・要件・契約

| 目的 | 機能・要件 | 不変条件・事前条件・事後条件 |
| --- | --- | --- |
| 基準を判断で伝える | 最新の手動付与・明示的除外からタグごとに学習し、保留・訂正・取消を扱う | 正例と負例の両方の互換特徴があるときだけ学習。未判断・保留・自動結果を学習へ混ぜない。同じ写真の履歴を重複標本にしない。確定保存の後だけ次へ進む |
| 欲しい範囲を閲覧する | 全解析済み写真の0〜1の適合スコアを保存し、タグ別閾値で絞る | 閾値は初期0.60、0.00〜1.00の0.01刻み。未校正であり確率・正解率とは表示しない。手動付与は表示、手動除外と既存の取消抑制は非表示、履歴のない写真だけスコア以上で表示。閲覧・閾値変更では学習も画像解析も行わない |
| 判断を有効に使う | 境界・高スコア・探索から未判断候補を選ぶ | セッション内の保留を再提示しない。現在の写真は非同期更新で差し替えない。取得失敗を負例にしない。正負例不足でも手動判断を続けられる |
| 結果を保全する | 判定器と全スコア、閾値を永続化する | 判断・写真・パイプライン・学習世代を照合する。モデルとスコアは同一トランザクションで完成結果として公開。失敗・取消は直前の完成結果を保持し、旧結果と未解析を区別。停止・全解除後の古いジョブを書き戻さない |

## 学習と保存

- 既存の向き補正済みMobileNet特徴を正規化して使う。正則化付きロジスティック回帰をタグごとに決定的に再学習する。正負例を均等に重み付けし、標本の偏りをスコアの確率校正と同一視しない。
- 判断はタグ全体で共有し、互換な保存済み特徴を持つ最新の手動正負例を使う。アルバムとカメラの絞り込みは表示・新規特徴抽出対象に適用する。旧related-tag-contractの範囲内見本限定を置き換える。
- 写真解析は明示開始のみ。確定判断後の再学習は保存済み特徴だけを使い、読み取りや閾値操作から画像解析を開始しない。画面離脱後の常駐解析は行わない。
- `tags.db` v3は旧判断・履歴・再評価要求・自動結果を保持して追加表を作る。判定器、全スコア、タグ別の閾値と学習有効状態・世代を保存する。旧自動結果にConfidenceを推測で付けない。最初の完成した学習結果までは旧集合を維持する。
- 全スコアの公開時は現行パイプラインのキャッシュ済み写真を対象とする。モデルを保持できない正負例不足では前回の結果を残し、更新できない状態を示す。未解析・失敗はスコア0とせず未計算のまま。
- 自動結果全解除は全アルバムの当該タグの推定だけを削除し、学習有効状態を解除して世代を進める。判断と閾値は残す。
- 写真参照は既存のURI・メタデータ対応を継承し、移動・置換の同一性を推測しない。原本・EXIF・順位・共有選択・他タグを変更しない。写真の外部送信は行わない。

## UIと非同期処理

Claudeの参照HTMLに従って4列格子・状態切替・写真追加・一括訂正・その他を保持する。スライダーのドラッグ中は数値を更新し、操作確定で保存と一覧絞り込みを行う。保存失敗時は元の閾値へ戻して再操作できる。閾値反映で既存の閲覧対象が消える場合にも詳細閲覧中の写真は保持する。

「基準を教える」は含めない・保留・含めると直前取消を持つ。保存中は変更とBackを禁止し、保存失敗時は写真と操作を保持する。通常の拡大閲覧のスワイプは移動のみ。

## 計測と検証

学習開始〜終了・標本数・スコア計算枚数、閾値操作〜一覧反映、保存失敗を固定名と数値だけで診断へ記録する。写真名・URI・タグ名をログへ出さない。

単体: 訂正による境界変化、独立した複数タグ、材料不足、不正特徴、非有限値、保留、候補重複防止、閾値単調性。隔離DB: v1/v2移行、全スコアと閾値再読込、手動優先・取消抑制、古い判断/世代拒否、停止/全解除、障害注入rollback。実機: 合成写真と隔離DBによる新操作と実画面のキャプチャ、既存タグ画面の回帰。実写真の鳥種精度・大量処理・発熱・確率校正は別の未検証範囲として記録する。
