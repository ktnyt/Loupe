# 状態表示の契約と対象

Issue #17の実装前の対象整理。表示仕様はClaudeの参照HTML確認後に確定する。現時点では棚卸しのみで、実装・実機検証は未完了。

## 目的と境界

写真と操作に集中できるよう、可視の状態説明文を形・進捗・数値で伝える。短い操作名、機能見出し、写真メタデータ、入力条件、安全確認は残す。状態説明は読み上げに保持し、情報ダイアログに旧状態文を移すだけでは完了としない。

不変条件は原本・順位・タグ推論・選択・外部送信条件の保持。失敗を成功に見せず、再試行は明示操作で行う。前画面の遅延結果を新画面へ反映しない。件数未測定を0や100%にしない。JobStateのreadyとfailedは重なり得るため差引計算しない。

## 対象一覧

| 対象 | 状態表示の経路 | 保持する情報・操作 |
| --- | --- | --- |
| 写真・アルバム一覧 | subtitleの読み込み・索引準備・空・取得失敗、更新失敗通知 | 実件数、アルバム名、既存一覧、再読み込み |
| 一覧サムネイル | 順位読込失敗のCanvas文字、プレビュー失敗 | 順位の数値、連写枚数、選択、読み上げの原因 |
| 連写 | heroの読込・失敗、strip待機・失敗、読込済み数、順位未決定・途中・読込失敗 | 位置・順位の数値、再試行、hero先行描画 |
| 写真詳細 | 原本待ち、低解像度preview、原本失敗、情報シート内の状態文 | 写真名・寸法・カメラ情報、前後・共有、再試行、画質差の識別 |
| 比較 | 写真取得失敗通知 | A/B、順位決定操作、拡大とBack |
| 共有 | 未決定連写、準備Sheet、失敗Sheet、キャンセル・形式不適合・共有先なし通知 | 対象枚数・形式、ソート、中止、再試行、選択に戻る |
| タグ | 読込・空・保存中、成功/失敗通知、付与あり/なし・自動/手動、解析と自動付与の進捗・完了/失敗 | タグ名、入力制約、実件数、停止/結果、推論上の注意・削除確認 |
| クラウド | 認証不足、接続/検証/復元/保存の進捗と結果、TLS/host失敗、ログアウト、busy | 3入口、明示的な実行、確認文、FLAG_SECURE |
| 同期設定 | 集計中/失敗、設定ON/OFF・権限、背景状態、前提不足 | 対象の機種/撮影日/容量、権限の意味、破壊的操作の確認 |
| 写真のプレビュー | 準備・待機・停止・部分失敗・未知・完了 | 既知のready/total/failed、再開操作、実更新時刻 |
| 共通の通知 | 順位保存、権限保存、登録済み、中止等のToast | 原因を識別する形、読み上げ、既存操作への復帰 |

#16のダッシュボードでも同じ状態表現を使う。ThumbHash/preview/タグ解析/自動付与を別工程として扱い、未測定の工程に推定値を表示しない。

## 検証の区分

変更前は0.17.20、25128PNA1Gで合成6枚・遅延loaderを使い、連写の読み込み文・失敗文・読込済み件数を確認した。変更後は短時間/長時間/失敗/再試行/中止/未知、320/400dp、文字倍率1/1.3、読み上げノードと実行可能な操作を確認する。実クラウドへの送信や写真原本の変更を合成検証で代用したと報告しない。
