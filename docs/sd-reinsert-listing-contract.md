# SDを挿し直した直後の一覧確認

- 文脈。SDのボリュームがマウント済みでも、その直後にAndroidから取得したDCIMの一覧が0件になる場合がある。実機では写真の場所を直接指定できても、フォルダを列挙できず、取り込みが0件で終了したことがある。
- 目的。差し替え直後に空に見えるカードをすぐに写真なしと扱わず、安全な範囲で自動取り込みを続ける。
- 契約。マウント済みの外部SDを読み取る既存経路で、完全な一覧が写真・動画とも0件、または読み込み中の場合だけ、短く待って同じ接続で1回確認し直す。既存の一覧取得の時間上限、キャンセル、読み取り許可、選んだフォルダ、取り込み元と保存先、取り外し世代の確認を維持する。正常に候補がある回は一覧を追加で問い合わせない。
- 2度目も完全な空の場合、同じボリューム・選択範囲にある少数のMediaStore登録を候補にする。既存の読み取り許可を使って、該当する1枚の文書の存在を、完全な単一行の照会で直接確認できた場合だけ、一覧に矛盾があると判断する。登録だけ、別カード、別フォルダ、曖昧な照会は証拠にしない。矛盾した一覧から取り込みを始めず、件数を確定せず、元カードの再接続を案内する。
- 本当に空のフォルダ、動画だけ、形式の絞り込みで0件、候補の写真にAndroidへの登録待ちがある場合は、従来どおり区別する。個別の写真がAndroidに未登録の場合も、フォルダ全体が空として表示しない。
- 一覧の再確認ではオリジナルと履歴を変更せず、Androidへのファイル登録やストレージ操作を行わない。再確認してもAndroidが以前のカードや古い一覧を返す場合は、利用者に取り込み元の挿し直しを案内する。
- 検証。空→正常、読み込み中→正常、実在する写真を取りこぼした空、本当に空、古い索引、別フォルダ、切断・許可失効・中止・保存先変更を区別する。前回確認した1,407件の通常動作と新規準備時の登録待ちを壊さない。

## 取り込み元の検出

- LoupeはAndroidの接続通知とマウント情報で登録済みカードを検出する。接続時の自動取り込みを有効にしている場合は、読み取り許可のある登録済みフォルダと保存先を確認して取り込む。手動開始と長押しも、Androidが認識している取り込み元を使う。
- カードを差し替えた場合の選択と登録は[SDカード差し替え時の契約](sd-source-swap-contract.md)に従う。SDカード取り込み設定でフォルダや取り込み形式を選べる。USBリーダーの再接続やSDカードのマウント操作は利用者とAndroidが行う。
