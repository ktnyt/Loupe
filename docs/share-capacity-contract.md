# 共有できる容量

## 目的と要件

写真を繰り返し共有でき、容量上限を超える選択では共有を始めない。受信側へ渡した一時コピーと写真原本を保全する。共有対象は既存の選択・同率1位・絞り込みをまたぐ選択の規則に従う。

## 契約

- 1回の出力ファイル合計は512 MiB以下。ちょうどは可。保持済みの共有コピーはこの合計に含めず、従来の24時間を保持する。端末の空き容量による書込失敗は別に扱う。
- JPEGと元の形式を別に判定する。既存JPEGと元形式は元ファイルのサイズ、RAWからのJPEGは抽出・向きのEXIF書込を済ませた最終サイズを使う。RAW元サイズをJPEGサイズと見なさない。
- 端末のRAWの測定は背景で行い、画像本体の展開はせずJPEG抽出だけを使う。同じURI・サイズ・更新日時の結果を再利用し、古い選択の結果を新しい画面へ適用しない。
- クラウドRAWの原本を選択しただけでは取得しない。出力サイズ未確認の形式は「?」とし、明示的な共有操作で既存の準備を始めて実サイズを確認する。未確認を上限以内と表示しない。
- 共有入口は使える形式が1つでもあれば有効。全形式が超過、または使える形式がなく測定中・失敗のときは無効。共有メニュー・登録共有先も各形式で判定する。ソートは従来の順位未決定条件に従う。
- 選択解除・1位だけの切替・形式変更で再判定する。準備は固定した選択と形式を再検査し、全件成功まで外部アプリを開かない。失敗・中止は今回のコピーだけを片付ける。
- 原本、永続プレビュー、過去の共有コピー、選択、順位、タグを容量調整のために削除しない。

## 表示

[Claudeの参照HTML](design/loupe-share-capacity.html)を基準とする。既存の枚数の札の右に容量の札を置き、必要なら札の行を折り返す。写真や操作に重ねない。

- 通常は`130 / 512 MiB`。1バイトでも超過なら切り上げて`512.1 / 512 MiB`と赤い警告にする。
- 測定中は進行の印と`/ 512 MiB`、失敗は警告と`確認できません`、取得を後で行う未確認は通常色の`? / 512 MiB`。
- 札は28dp以上、角丸14dp、背景`#1F1F22`、線`#3A3A3F`、13sp。警告の線`#FF8A7A`、文字`#FFB4A8`。無効ボタンは既存の背景`#26262A`と文字`#626B72`。
- 形式にサイズを併記し、無効はAndroidのenabledとアクセシビリティ状態でも示す。超過理由・上限・選択を減らす復帰操作を読み上げで伝える。

## 検証

ホスト検査、合成画像の実機検査、実写真による失敗条件の再確認を分ける。境界、保持コピー、形式差、選択解除、順位条件、旧要求破棄、判定前の押下、メニュー・登録先の無効操作を確認する。写真原本や個人情報をissueへ載せない。
