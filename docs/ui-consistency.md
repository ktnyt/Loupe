## 不変条件と完了条件

- 原本・順位・タグ・選択・認証・同期/削除/共有の保存と送信条件を変えない。#1のタグ推論は対象外。
- 事前に対象APKのcommit/version、端末、寸法、文字倍率、画面状態を特定する。未マージAPKで確認した結果をmainの確認として扱わない。
- 比較画像は合成データを使い、同じ寸法・状態で実機とHTMLを並べる。写真内容、OS領域、書体等の差を具体的に分け、一括して不一致を無視しない。
- 操作領域48dp以上、文字を縮小/省略しないこと、状態変更時の位置安定性、無効操作を実際に発火できないことを確認する。
- 観測した不一致だけを位置と根拠付きで記録する。未確認を一致扱いせず、見た目だけで操作・読み上げ・中断復帰を合格にしない。
- UI変更時は独立UI/UX評価、Cold/Security Reviewと回帰確認を行う。範囲内の未解決指摘と実施不能の必須検証がある間は#8を閉じない。

比較基準の依存先#17と#39はmainへ統合済み。横断確認の基準APKは0.17.22（47）、mainコミット`8deaf64`、端末25128PNA1G（Android 16）とする。320/400dp、文字倍率1/1.3の合成データを使い、現在のAPKで比較画像を再取得する。個別issueの既存結果は調査資料として参照し、横断検証の代わりにはしない。横断確認は未完了。

## 残る比較対象

- タグ一覧：版29の左寄せ行と主CTAに対し、現行は中央文字行と装飾のない作成ボタン。サムネイルと件数のための追加走査は行わず、既存のタグ一覧取得と操作を保つ。
- 同期設定：版29のカード配置に対し、現行は説明文と操作の縦列。安全説明と既存の設定・権限・送信条件を保持し、状態を直接変更しない表示用スイッチを維持する。
- 版29のローカル表示では画面枠だけとなるため、画面を比較済みとはしない。独立して表示可能な採用HTMLを先に用意する。
- タグ詳細・写真選択・共有の残存箇所と、最新HTMLを使った独立した横断UI評価は未完了。

## タグ一覧・同期設定の実装契約

採用HTMLは `docs/design/loupe-issue8-consistency.html`。タグ一覧の行は最低72dp、左20/右16/上下12dp、40dpの固定タグ印、16spの省略しない名前、20dpの進む印。下部作成CTAは最低52dp、角丸26dp。読み込み失敗から既存の再読み込みへ戻れることを保つ。

同期設定は左右16dp、内側16dp・角丸16dpのカードを12dp間隔で並べる。見出しと本文をスクロールし、下部の設定/その他は固定する。表示専用スイッチは保存済みの値のまま、collection・info・permissionState・progressを相互推測せず表示する。既存の安全説明、権限要求とボタンの表示条件、7/30/90日選択時に同じ値でも自動削除を無効化する処理を変えない。読み取り更新だけを理由に新しい操作禁止を追加しない。
