# 画面横断のデザイン一致契約

Issue #8。個別画面の修正を重複実装せず、元のデザインと明示された変更要求と実機の配置・形・色・余白・有効無効状態を横断確認する。各個別issueの完了だけで全体の一致を保証しない。

## 比較の基準

比較の基準はClaude Design「Loupe UI ブラッシュアップ」（artifact `8da8486b-4b3b-4136-81cc-dddbe01f544e`）と2026-10-25に取得した書き出し。個別issueのHTMLは、そのissueで要求された変更部分だけを補う。現行Androidに合わせた再現用HTMLは、元デザインとの一致を証明しない。元アートボード・明示された変更要求・派生HTML・実機の対応を確認してから採用する。ダミーの写真や件数を実値と混同しない一方、写真サムネイルや件数を表示する構造までダミーとして削除しない。

原本・保存条件を保持することは、現行のUI構造や読み取り実装を固定することではない。デザインのために必要な読取処理は設計し、実装上の制約で要素を省く場合はデザイン適用未完了として扱う。新規のUI修正は元アートボードを示してClaudeへ依頼し、完成案がその基準を保つか確認してから実装する。

## 不変条件と完了条件

- 原本・順位・タグ・選択・認証・同期/削除/共有の保存と送信条件を変えない。#1のタグ推論は対象外。
- 事前に対象APKのcommit/version、端末、寸法、文字倍率、画面状態を特定する。未マージAPKで確認した結果をmainの確認として扱わない。
- 比較画像は合成データを使い、同じ寸法・状態で実機とHTMLを並べる。写真内容、OS領域、書体等の差を具体的に分け、一括して不一致を無視しない。
- 操作領域48dp以上、文字を縮小/省略しないこと、状態変更時の位置安定性、無効操作を実際に発火できないことを確認する。
- 観測した不一致だけを位置と根拠付きで記録する。未確認を一致扱いせず、見た目だけで操作・読み上げ・中断復帰を合格にしない。
- UI変更時は独立UI/UX評価、Cold/Security Reviewと回帰確認を行う。範囲内の未解決指摘と実施不能の必須検証がある間は#8を閉じない。

## 参照HTMLの確認

`loupe-ui-2026-10-25.html` は51画面を含むが、ローカルでは必要なランタイムがなく画面が白くなる。Claude内の元画面を見て、独立して表示できるHTMLの書き出しを確認してからAndroidへ適用する。

`loupe-issue8-consistency.html` はタグの写真・件数と同期の直接操作を失った派生案のため、比較の基準にしない。APK 0.17.24（49）の52画像による検査は、この派生案の文字欠け・操作領域等の確認に限られ、元のデザインとの一致を示さない。

## タグ一覧の読取処理

目的は、写真と枚数から開きたいタグを選べること。対象アルバムとカメラの絞り込みを維持し、名前だけの一覧へ縮退させない。

- 事前条件：既存のGalleryIndexから対象写真を読み、TagStoreからタグ・判断・自動付与を読む。写真一覧と同じsource識別を使う。
- 不変条件：一覧を開くだけではタグ判断や原本を変更せず、推論や同期を開始しない。タグ付き件数は人の付与と有効な自動付与を重複なく数え、該当しない件数は人の除外だけを数える。対象外写真と古いsourceの判断を混ぜない。
- 事後条件：各タグに対象内の件数と代表写真を表示する。代表は対象内のタグ付き写真の先頭から選ぶ。該当写真がない場合は空の枠を表示し、取得前・取得失敗を0枚と表示しない。
- 読み取りは画面描画を止めず、画面を離れた後に古い結果を反映しない。写真の読込失敗でもタグを開く操作は維持する。読取時間と表示までの時間は実機で確認する。
- タグ一覧のHTMLが元デザインと後続要求を保つことを確認してから実装する。#1の推論改善は含めない。

## 同期画面の観測値

T1/T11の参照は `docs/design/loupe-t1-t11-applied.html`。同期・確認・自動削除の3カードに直接操作を置く。権限と削除確認、期間選択時の削除停止は既存条件を保つ。

「最後の同期」は保留なく同期ループを終え、中断されなかった時点の `syncFinishedAt` を表示する。状態の更新時刻から推測せず、記録がない場合は「—」。確認カードは前回選んだ写真の復元検証結果を表示し、全写真の確認完了を意味しない。既存記録から推測せず、結果記録がなければ未確認として扱う。

## アルバム・写真一覧の表示契約

目的は写真とアルバムを見渡して選べること。参照は `docs/design/loupe-result-lists-tagdetail-applied.html` のアルバム・写真一覧で、元の横送り・2列アルバム・4列写真を保つ。

- 最近の写真は300×225dpの写真と写真上の日時、上40dp・左右20dpの見出し。ほかのアルバムは104×78dpの写真と折り返す名前を使う。文字を省略・縮小しない。
- アルバム見出しは24sp・行高32sp、件数14sp。2列の写真は高さ160dpを保持し、一覧全体と見出しは一緒にスクロールする。
- 取得元・並び順・遅延プレビュー読込、世代の確認、アルバム選択、Back、タブ・スクロール・選択保持は既存処理を維持する。表示のために原本を保存・送信・削除しない。
- 320/400dp・文字1/1.3倍で写真寸法、長い名前、操作領域、実機と参照の一致を確認する。読み取り失敗は0件と混同せず、既存の再試行を保持する。

ソート結果とタグ詳細のHTMLは、既存の全順位・同率・取り消し・タグ訂正等の入口が未反映のため追加設計中。これらの機能を削除する根拠に使わない。
